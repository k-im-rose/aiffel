# 그내종 공개 데모 (정적 사이트)

### ▶ [홈페이지 바로 가기](https://k-im-rose.github.io/geunaejong-demo/) · [코드 저장소](https://github.com/k-im-rose/aiffel/tree/investment-ai-briefing/investment-ai-briefing)

그내종. 그래서 내 종목은? 의 공개 데모입니다. 가상 투자자 프로필과 2026-11-17에 실제 수집한 뉴스로 만든 브리핑을 보여 줍니다.
이 저장소는 배포용 정적 파일만 담고 있습니다. 프로젝트 전체(코드, 문서, 평가)는 https://github.com/k-im-rose/aiffel/tree/investment-ai-briefing/investment-ai-briefing 에 있습니다.

- 실제 로그인은 구현되어 있지 않습니다(화면 시안). **데모 체험하기** 버튼으로 들어갑니다.
- 수정한 프로필·메모·점검 목록은 방문자 브라우저에만 저장되고 다른 방문자에게 영향을 주지 않습니다.
- 실제 투자 프로필과 개인 기록은 포함하지 않았습니다.
- 이 데모는 **교육 및 비상업적 포트폴리오 목적**으로 운영합니다.
- 음성(MP3)은 가상 프로필 데모 브리핑만 공개했고, [edge-tts](https://github.com/rany2/edge-tts)(Microsoft Edge의 온라인 읽어주기 음성, 진행자 ko-KR-SunHiNeural·ko-KR-InJoonNeural)로 생성해 `media/`에 두었습니다. 생성된 음성의 저작권은 아직 불분명하나 비상업 이용이라는 안내를 받아 공개했습니다. 실제 프로필 기반 음성은 공개하지 않습니다.
- 이 서비스는 투자 판단을 돕는 개인 리서치 도구이며 매수·매도를 권유하지 않습니다.
