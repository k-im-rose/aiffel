# 시연 영상 대본 (3분 이내)

> 화면 녹화 + 목소리로 설명. 대본은 그대로 읽지 않아도 된다. 흐름만 따라가면 된다.
> 사이트: https://k-im-rose.github.io/aiffel/study-terms-app/

## 찍기 전 준비

- 시크릿 창(새 창)으로 사이트 열기 → 기록이 없는 깨끗한 상태에서 시작
- 컴퓨터로 찍는다면 브라우저 창을 크게, 휴대폰이라면 세로 화면
- 녹화 방법
  - **맥:** `Shift + Cmd + 5` → '전체 화면 기록' 또는 '선택 부분 기록' → 옵션에서 마이크 켜기
  - **아이폰:** 제어 센터 → 화면 기록 버튼을 길게 눌러 마이크 켜기
- 한 번에 다 찍기 어렵으면 장면별로 나눠 찍고 이어 붙여도 된다

## 대본

### 1. 문제 (0:00 ~ 0:30) — 30초 소개

> 화면: 첫 화면 (제목 '아, 그게 뭐더라?')

"AI 에이전트 과정을 들으면서 강의마다 하네스, MCP, RLS 같은 새 용어가 쏟아졌어요.
읽을 땐 아는 것 같았는데, 실습에서 다시 만나면 뜻도, 설명도, 어디서 봤는지도 떠오르지 않았어요.
분명 봤는데 생각이 안 날 때 누구나 하는 그 말, '아, 그게 뭐더라?'
그 순간 바로 열어 보라고 만든 용어 사전 겸 암기장이에요."

### 2. 찾기 (0:30 ~ 0:55)

> 화면: 검색창에 `ㅎㄴㅅ` 입력 → 하네스가 남음 → 지우고 `mcp` 입력

"실습하다 막히면 검색창에 바로 쳐요. 초성만 쳐도 되고, `ㅎㄴㅅ`만 쳐도 하네스가 나와요.
영어로 쳐도, 한글로 쳐도 같은 카드가 나와요."

### 3. 읽기 (0:55 ~ 1:25)

> 화면: MCP 카드 열기 → 노란 칸, DEFINITION, 쉽게 말하면, 예를 들면 순서로 짚기

"카드에는 교육자료에 나온 뜻이 있고, 그 아래 '쉽게 말하면'에 비유가 있어요.
MCP는 'USB-C 단자처럼 AI와 도구를 같은 모양으로 잇는 것'이에요.
'예를 들면'에는 실제로 쓰는 장면이 있고, 출처에 어느 강의 자료에서 나왔는지도 보여요."

### 4. 나의 언어로 쓰고 마치기 (1:25 ~ 2:10) — 이 앱의 핵심

> 화면: 메모장 비운 채 '마치기' 누르기 → 안내 문구 → 메모장에 직접 쓰기 → '저장됨 ✓' → '마치기'

"이 앱의 핵심 규칙이에요. 읽기만 하고 '마치기'를 누르면… 막혀요.
'내 설명을 먼저 써야 마칠 수 있어요.'
그래서 나의 언어로 한 줄 써 봐요. '여러 도구를 AI에 꽂아 쓰게 해 주는 공통 콘센트.'
쓰는 대로 저장되고, 이제 '마치기'가 눌려요. 목록에도 '✓ 마치기'로 바뀌었어요."

### 5. 진도 보기 (2:10 ~ 2:35)

> 화면: 진행률 `마치기 1 / 144` → 섹션 펼치고 접기 → '다시 보기' 필터

"용어 144개가 교육자료별로 나뉘어 있고, 섹션마다 몇 개를 마쳤는지 보여요.
헷갈리는 건 '다시 보기'로 표시해 두고, 필터로 그것만 모아서 복습해요.
휴대폰에서도 똑같이 쓸 수 있어요."

### 6. 마무리 (2:35 ~ 3:00)

> 화면: 첫 화면 또는 휴대폰 화면

"처음엔 투자 뉴스를 자동으로 분석해 주는 앱을 만들고 싶었지만, 첫 조각으로는 너무 커서 잘랐어요.
대신 흐름 하나가 끝까지 되는 것부터 만들었어요.
다음에는 오늘 공부할 용어를 추천하고, 로그인을 붙여 동기들이 각자 자기 기록으로 함께 쓰게 할 계획이에요."

## 시간이 넘칠 때 줄일 곳

- 2번 찾기에서 영어 검색은 빼도 된다
- 5번에서 휴대폰 이야기는 빼도 된다
- 6번은 마지막 한 문장(다음 계획)만 남겨도 된다
