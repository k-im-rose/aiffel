# 시연 영상 — 자막 대본 (3분 이내, 말 없이)

> 화면을 녹화하고, 장면마다 아래 자막을 화면에 넣는다. 자막은 한 장면에 한두 줄만.
> 사이트: https://k-im-rose.github.io/aiffel/study-terms-app/

## 찍기 전 준비

- **시크릿 창**으로 사이트 열기 → 기록 없는 깨끗한 상태에서 시작
- 마우스를 천천히 움직이고, 누르기 전에 1초 멈추기 (보는 사람이 따라올 수 있게)
- 녹화 방법
  - **맥:** `Shift + Cmd + 5` → '선택 부분 기록'으로 브라우저 창만 녹화
  - **아이폰:** 제어 센터 → 화면 기록
- 자막 넣기: **iMovie**(맥 기본 앱) → '타이틀', 또는 **CapCut** → '텍스트'

## 장면과 자막

| # | 시간 | 화면에서 할 일 | 자막 |
|---|---|---|---|
| 1 | 0:00 ~ 0:15 | 첫 화면을 가만히 보여 주기 | **강의마다 쏟아지는 새 용어들.** 읽을 땐 알 것 같은데, 실습에서 다시 보면… |
| 2 | 0:15 ~ 0:25 | 제목 '아, 그게 뭐더라?' 확대 또는 마우스로 가리키기 | **"아, 그게 뭐더라?"** 그 순간 바로 여는 용어 사전 겸 암기장 |
| 3 | 0:25 ~ 0:45 | 검색창에 `ㅎㄴㅅ` 입력 → 하네스만 남는 것 보여 주기 | **초성만 쳐도 찾아요.** ㅎㄴㅅ → 하네스 |
| 4 | 0:45 ~ 0:55 | 검색어 지우고 `mcp` 입력 | **영어·한글 어느 쪽으로 쳐도 돼요** |
| 5 | 0:55 ~ 1:20 | MCP 카드 열기 → DEFINITION, 쉽게 말하면, 예를 들면을 차례로 가리키기 | **교육자료의 뜻 + 쉬운 비유 + 실제 장면** |
| 6 | 1:20 ~ 1:35 | 메모장이 빈 채로 '마치기' 누르기 → 안내 문구가 뜨는 것 | **읽기만 하고 '마치기'? 막혀요.** |
| 7 | 1:35 ~ 1:55 | 메모장에 직접 한 줄 쓰기 (예: 여러 도구를 AI에 꽂아 쓰게 해 주는 공통 콘센트) → '저장됨 ✓' | **나의 언어로 설명을 써야** 아는 걸로 쳐요. 쓰는 대로 자동 저장 |
| 8 | 1:55 ~ 2:05 | '마치기' 누르기 → 목록에 '✓ 마치기' | **이제 '마치기' 완료!** |
| 9 | 2:05 ~ 2:25 | 진행률 `마치기 1 / 144` 가리키기 → 섹션 펼치고 접기 | **교육자료별 용어 144개.** 섹션마다 진도가 보여요 |
| 10 | 2:25 ~ 2:40 | 아무 용어나 '다시 보기'로 바꾸고 → '다시 보기' 필터 누르기 | **헷갈리는 건 '다시 보기'로 모아서 복습** |
| 11 | 2:40 ~ 2:50 | (있으면) 휴대폰 화면으로 전환 | **휴대폰에서도 똑같이** |
| 12 | 2:50 ~ 3:00 | 첫 화면으로 돌아오기 | **다음:** 오늘의 용어 추천 · 로그인으로 동기들과 함께 |

## 시간이 넘칠 때 줄일 곳

- 4번(영어 검색), 11번(휴대폰)은 빼도 된다
- 자막은 다 읽을 시간(한 줄에 약 3초)을 주고 다음 장면으로 넘어가기
