## 사용 방법

### 한눈에 보기

> **찾는다 → 읽는다 → 나의 언어로 쓴다 → '마치기'를 누른다**

### 1. 찾기 🔍

맨 위 **검색창**에 궁금한 말을 쳐요. 치는 동안 바로바로 목록이 줄어들어요.

- 영어로 쳐도, 한글로 쳐도 돼요. `mcp`, `MCP`, `연결 규격` 모두 같은 카드가 나와요.
- 첫 글자 자음만 쳐도 돼요. `ㅎㄴㅅ` → **하네스**
- 찾은 글자는 노란 형광펜으로 칠해져요.

### 2. 고르기 👆

목록에서 용어를 눌러요.

- **컴퓨터:** 오른쪽에 카드가 열려요.
- **휴대폰:** 카드 화면으로 넘어가요. 돌아올 땐 `← 목록`이나 브라우저 **뒤로 가기**를 눌러요.

### 3. 읽기 📖

카드는 위에서 아래로 읽어요.

| 카드에 있는 것 | 뜻 |
|---|---|
| `WORD 112` | 용어 번호 |
| `출처 02-06` | 이 용어가 나온 교육자료 번호 |
| `입문` `실전` `심화` | 난이도. 입문이 가장 쉬워요 |
| 큰 영어 + 노란 칸 | 용어 이름, 한글 이름, 약어면 영어 전체 이름 |
| **DEFINITION** | 교육자료에 나온 뜻 |
| **쉽게 말하면** | 일상 속 비유로 푼 설명 |
| **예를 들면** | 실제로 쓰는 장면 |
| **연결할 용어** | 같이 알면 좋은 용어. 누르면 그 카드로 가요 |

### 4. 나의 언어로 쓰기 ✏️

**MY NOTE**의 노란 메모장에 이 용어를 내 말로 한두 문장 써요.

- 저장 버튼이 없어요. **쓰는 대로 저장**되고 `저장됨 ✓`이 떠요.
- 남의 설명을 베끼기보다, 친구에게 말해 주듯 써야 오래 기억나요.

### 5. 상태 누르기 ✅

메모장 아래 버튼 세 개로 지금 얼마나 아는지 골라요. 세 버튼의 뜻은 맨 위 제목 아래 안내 밑에도 적혀 있어요.

| 버튼 | 언제 누르나요? |
|---|---|
| **알아보기** | 처음 보거나 아직 잘 모를 때 (처음엔 모두 이 상태예요) |
| **다시보기** | 조금 알겠는데 아직 헷갈릴 때 |
| **마치기** | 내 말로 설명할 수 있을 때 |

> ⚠️ **마치기**는 메모장에 설명을 써야만 눌러져요. 읽기만 하고 "알았다" 하고 넘어가는 걸 막기 위해서예요.

### 6. 진도 보기 📊

| 버튼·표시 | 뜻 |
|---|---|
| `마치기 3 / 144` | 전체 용어 중 마친 개수 |
| **전체 · 알아보기 · 다시보기 · 마치기** | 그 상태인 용어만 골라 보는 버튼. 아래 숫자는 개수예요 |
| **자료별로 보기** | 교육자료(01-04, 02-01 …)마다 묶어서 보기 |
| **전체 목록** | 묶지 않고 한 줄로 쭉 보기 |
| `▸ 02-04 백엔드와 데이터베이스  3 / 27` | 섹션 이름. 누르면 펼쳐지고(▾) 다시 누르면 접혀요. 오른쪽 숫자는 그 섹션 진도예요 |

### 처음 화면으로 🏠

맨 위 제목 **아, 그게 뭐더라?** 를 누르면 **홈 화면**으로 가요. 홈 화면은 이렇게 생겼어요.

| 홈 화면에서는 | 이렇게 돼요 |
|---|---|
| 검색창 | 비어 있어요 |
| 필터 | **전체**가 눌려 있어요 |
| 목록 | **자료별로 보기**에서 섹션(01-04, 02-01 …)이 **모두 닫혀** 있어요 |
| 오른쪽 카드 (컴퓨터) | 비어 있어요. 용어를 누르면 카드가 떠요 |
| 휴대폰 | 카드를 보고 있었어도 목록 화면으로 돌아와요 |
| 내 설명·상태 | **그대로 남아요.** 지워지지 않아요 |

### 용어 주소 보내기 🔗

카드를 열면 주소 끝에 `#mcp`처럼 용어 이름이 붙어요. 이 주소를 복사해서 보내면 받은 사람도 그 카드가 바로 열려요.

### 키보드 지름길 (컴퓨터)

| 키 | 하는 일 |
|---|---|
| `/` | 검색창으로 바로 가기 |
| `Enter` | 검색 결과 첫 번째 카드 열기 |
| `Esc` | 검색어 지우기 |

### 알아 두세요 💾

- 기록은 **서버(DB)**에 저장돼요. 창을 닫았다 열어도, 브라우저 기록을 지우지 않는 한 그대로 있어요.
- 로그인하지 않으면 **브라우저마다 따로** 기록돼요.
- 맨 위 **Google로 로그인**을 누르면 휴대폰·PC 어디서든 같은 기록을 봐요. 로그인 전에 쓴 기록은 로그인할 때 계정으로 옮겨져요 (계정에 이미 있는 용어는 계정 쪽을 남겨요).
- 휴대폰에서 **홈 화면에 추가**하면 앱처럼 '아그뭐' 아이콘으로 열 수 있어요.

## 해결하는 문제

AI 개발을 막 배우는 초보자가, 강의에서 본 용어를 제대로 이해하지 못한 채 넘어가 실습 때마다 다시 찾아본다.

| 막히는 지점 | 이 앱의 대응 |
|---|---|
| 뜻을 잊어버린다 | 용어마다 직접 쓴 설명이 남아서 바로 다시 본다 |
| 설명을 못 한다 | 나의 언어로 설명을 써야 '마치기'로 체크된다 |
| 어디서 봤는지 못 찾는다 | 용어마다 출처(자료 번호)가 붙어 있다 |
| 비슷한 용어가 헷갈린다 | 연결할 용어로 바로 넘어가 비교한다 |

## 기능

- **사전처럼 찾기:** 열자마자 검색창에 커서. 타이핑하는 즉시 결과가 줄어든다. 영어·한글·대소문자 구분 없이, 초성(`ㅎㄴㅅ` → 하네스)으로도 찾는다. `/` 검색 · `Enter` 첫 결과 열기 · `Esc` 지우기
- **용어 144개:** 교육자료 01-04, 02-01 ~ 02-07에 나온 실전 개발·AI 용어. 겹치는 용어는 처음 나온 자료에 하나만 두고 출처를 함께 적었다
- **자료별 섹션:** 섹션을 눌러 펼치고 접는다. 섹션마다 `마친 수 / 전체` 진행률. [전체 목록]으로 한 번에 보기도 된다
- **용어 카드:** 영어 이름, 한글 이름, 약어의 영문 풀네임, PDF 기반 한 줄 뜻, **쉽게 말하면**(초등학생 눈높이 비유), **예를 들면**(실제 장면), 연결할 용어, 난이도(입문·실전·심화)
- **MY NOTE:** 줄 그은 노란 메모장에 나의 언어로 설명을 쓴다. 쓰는 대로 자동 저장되고 `저장됨 ✓`이 보인다
- **상태:** 알아보기 → 다시보기 → 마치기. 설명이 비어 있으면 '마치기'를 누를 수 없다(공백만 넣어도 막힘). 마친 용어의 설명을 지우면 '다시보기'로 되돌아간다
- **휴대폰:** 목록 → 카드 → `← 목록` 또는 브라우저 뒤로 가기. 홈 화면에 추가하면 이름이 '아그뭐'로 보인다
- **구글 로그인 (선택):** 로그인하면 기기 사이에서 같은 기록. 로그인 전 기록은 계정으로 옮긴다. 토큰은 서버가 httpOnly 쿠키로만 다룬다

## 실행

```bash
npm install
npm start
```

→ http://localhost:3000 (Supabase 설정이 없으면 로컬 SQLite 파일 `study-terms.db`에 저장)

시험: `npm test` (버리는 DB로 API의 조회·저장·검증·삭제를 확인)

## 구조

```
브라우저 (public/)  ──fetch──▶  Express API (server/)  ──▶  Supabase Postgres (배포) / SQLite (로컬)
```

| 파일 | 역할 |
|---|---|
| `public/index.html` · `styles.css` · `app.js` | 화면. 데이터는 모두 API로 불러오고 저장한다 |
| `server/index.js` | API 서버 (Express). 요청 검사, 화면 파일 제공 |
| `server/store/supabase.js` · `sqlite.js` | 저장소 두 가지. 환경변수에 Supabase가 있으면 Supabase, 없으면 SQLite |
| `server/terms.js` | 용어 원본(`data/*.js`)을 읽어 DB에 맞춘다 (서버가 켜질 때마다) |
| `data/terms.js` · `data/terms-02-0N.js` | 용어 원본. 새 강의 용어는 파일 하나를 더한다 |
| `supabase/schema.sql` | Supabase 표 만들기 (SQL Editor에 붙여 넣고 실행) |
| `test/api.test.js` | API 시험 |

| API | 하는 일 |
|---|---|
| `GET /api/terms` | 섹션과 용어 전체 |
| `GET /api/notes` | 내 기록 (로그인했으면 계정 기록, 아니면 헤더 `X-Device-Id`의 기록) |
| `PUT /api/notes/:termId` | 내 설명·상태 저장. 설명 없이 '마치기'면 400 |
| `DELETE /api/notes/:termId` | 그 용어의 내 기록 지우기 |
| `GET /api/auth/me` | 지금 로그인한 사람 |
| `GET /api/auth/google` | 구글 로그인 시작 (돌아오는 곳: `/api/auth/callback`) |
| `POST /api/notes/merge` | 로그인 직후, 이 기기의 기록을 계정으로 옮기기 |
| `POST /api/auth/logout` | 로그아웃 |

- 비밀값: `SUPABASE_URL`, `SUPABASE_SECRET_KEY`는 Render 환경변수(로컬은 `.env`)에만 둔다. 코드·git에 없다
- 표에는 RLS를 켜고 공개 정책을 두지 않는다 → 비밀 키를 가진 서버만 DB에 접근한다
- CSS·JS를 고치면 `public/index.html`의 `?v=` 숫자를 올린다

### 2026-11-04 · 화면, 배포, 다듬기

- **디자인:** 다크 그린 → 노랑·흰색·검정 포스터 무드로 변경. 글꼴은 Pretendard 하나로 통일, 이탤릭 없음

- **상태 이름:** 모름·헷갈림·설명 가능 → **알아보기 · 다시보기 · 마치기**. 버튼·목록·필터·진행률 모두 같은 이름
- **배포:** GitHub Pages. 배포 주소에서 성공 조건 3개와 규칙 다시 확인
- **머리말:** 한 줄 제목, 제목과 안내를 잇는 가로선(PC), 안내 문구 '외워야 할 게 있으신가요?', 간격·행간 조정
- **카드:** 노란 메모칸 너비를 가장 긴 용어 기준으로 고정, 셋째 줄은 약어의 영문 풀네임만
- **용어 144개로 확장:** 02-01 ~ 02-07에서 124개 추가, 자료별 섹션과 섹션별 진행률, 예시 보기 버튼 대신 정의 아래에 쉬운 비유와 예시
- **필터 버튼:** 개수를 이름 아래로 옮김 (개수가 1000이 넘어도 옆 여백 유지)
- **노란 메모칸:** 휴대폰에서 칸이 한 글자 폭으로 좁아져 세로로 길어지던 문제 수정(카드가 숨겨진 상태에서 너비를 0으로 재던 버그). PC에서는 칸을 1.5배(340px → 510px)로 넓힘
- **뒤로 가기:** 휴대폰에서 카드를 열면 방문 기록을 남겨, 사파리 뒤로 가기(스와이프 포함)로 목록에 돌아온다. 연결할 용어로 넘어간 뒤 뒤로 가면 이전 카드로. 주소 끝에 `#용어id`를 붙이면 그 카드로 바로 열린다 (예: `#rls`)
- **머리말 라벨:** `TERM NOTES` → `WHAT'S THE WORD AGAIN?`. '팀(Team) 노트'로 읽혀 공용 노트로 오해할 수 있어서, 제목 '아, 그게 뭐더라?'를 영어 입말로 옮긴 표현으로 바꿈
- **버전 2: API 서버와 DB:** Express API 서버 + DB(배포 Supabase, 로컬 SQLite). 용어는 `GET /api/terms`로 불러오고, 내 기록은 `/api/notes`로 저장·조회·삭제. 설명 없이 '마치기'는 서버·DB도 거절. 브라우저에 있던 옛 기록은 처음 열 때 서버로 옮김. 카드에 '기록 지우기' 추가, 불러오는 중·연결 실패·저장 실패 표시
- **버전 2 배포:** Render(서버+화면) + Supabase(DB). 예전 GitHub Pages 주소는 Render 주소로 넘겨 줌
- **구글 로그인:** 맨 위에 `Google로 로그인`. 로그인하면 휴대폰·PC에서 같은 기록, 로그인 전 기록은 계정으로 옮김. notes 표의 `device_id` → `owner_id`(`device:…` / `user:…`)
- **PC 머리말 선 다시 길게:** 상태 설명이 왼쪽으로 옮겨져서, 가운데 선은 다시 길게 뻗고 작은 글씨 두 줄은 오른쪽 끝으로. 안내와 상태 설명 사이 여백 16px → 24px
- **PC 머리말 정리:** 상태 설명을 휴대폰처럼 왼쪽 안내 바로 아래로 옮기고, 가로선 오른쪽에는 작은 글씨 두 줄만. 선과 작은 글씨는 제목 높이 가운데에 맞춤
- **PC 머리말 선:** 가운데 선을 제목 높이 가운데에 맞추고 120px로 짧게 고정. 오른쪽 설명은 선 바로 뒤에 붙고 남는 폭은 오른쪽 여백으로. 상태 라벨과 설명 사이도 넓힘
- **머리말 다시 배치:** '외워야 할 게 있으신가요? …' 두 줄을 제목 바로 아래로 옮기고, 가로선 오른쪽에는 상태 설명(알아보기·다시보기·마치기, 목록 라벨과 같은 모양)과 작은 글씨 두 줄. 상태 버튼에 마우스를 올려도 같은 설명이 뜬다
- **'다시 보기' → '다시보기':** 알아보기·마치기처럼 붙여 쓰기
- **휴대폰 제목 크기:** '아, 그게 뭐더라?'를 1.5배(32px → 48px)로
- **아이폰에서 제목이 늦게 눌리던 문제:** 뒤로 가기 뒤 사파리가 스크롤을 늦게 되돌리는 동안 누른 것이 무시되던 것을 막음(스크롤 위치는 앱이 직접 맞춤), 두 번 누르기 확대 판정 대기 없애기, 터치 기기에서는 제목 위 '마우스 올림' 효과 끄기
- **안내 문구:** '분명 봤는데 생각이 안 날 때 하는 말.' → '분명 봤는데 생각이 안 날 때 하는 말 있잖아요.'
- **용어마다 주소:** PC에서도 카드를 고르면 주소가 `…/study-terms-app/#mcp`처럼 바뀐다. 주소를 복사해 보내면 그 카드가 바로 열린다
- **제목 누르면 처음 화면:** 제목 '아, 그게 뭐더라?'를 누르면 홈으로. 홈 = 필터 '전체' + 자료별 보기 + 섹션 모두 닫힘 + 검색어 없음 + 맨 위. PC에서는 오른쪽 카드 자리도 비워 둔다 (기록은 유지)
- **머리말 라벨 다시:** `WHAT'S THE WORD AGAIN?` → `STUDY TERM NOTES`. 제목과 같은 말을 영어로 반복하는 느낌이고 외국인 대상도 아니라서, 무엇을 하는 곳인지 바로 보이게 (term은 꾸미는 명사라 단수)
- **카드 번호 라벨:** `CONCEPT 006` → `WORD 006`
- **'핵심 20개' 섹션 없애기:** 무엇이 핵심인지 기준이 흔들릴 수 있어서, 20개를 각 용어가 처음 나온 자료 섹션으로 옮김. 01-04에서 처음 나온 GenAI·환각·바이브 코딩·에이전트를 위해 `01-04` 섹션 추가. WORD 번호도 자료 순서대로 001~144로 다시 매김
- **개념 흐름 상자 빼기:** `요청 → 처리 → 응답` 같은 세 칸 상자가 무엇의 흐름인지 알기 어려워서 화면에서 뺌. 쉽게 말하면·예를 들면이 같은 역할을 한다 (데이터는 남김)
