# 아, 그게 뭐더라? (아그뭐)

### ▶ [사이트 바로 가기](https://k-im-rose.github.io/aiffel/study-terms-app/) · [코드 저장소](https://github.com/k-im-rose/aiffel/tree/main/study-terms-app)

헷갈리는 용어를 사전처럼 찾아보고, 나의 언어로 설명하며 외우는 용어 사전 겸 암기장.
모두의연구소(MODULABS) AIFFEL AI 에이전트 과정 **Main Quest 01**로, 에이전트(Claude Code)와 함께 만들었다.

> 분명 봤는데 생각이 안 날 때, 누구나 하는 그 말.
> 그 말이 나오는 순간 바로 열어 보라고 지은 이름이에요.

- **사이트:** [k-im-rose.github.io/aiffel/study-terms-app](https://k-im-rose.github.io/aiffel/study-terms-app/) (로그인 없음, 기록은 그 브라우저에 저장)

- 에이전트 작업 규칙: [AGENTS.md](AGENTS.md) · 교육자료에서 뽑은 용어 원본: [용어집.md](용어집.md) · 회고: [retrospective.md](retrospective.md)

## 사용 방법

### 한눈에 보기

> **찾는다 → 읽는다 → 나의 언어로 쓴다 → '마치기'를 누른다**

### 1. 찾기 🔍

맨 위 **검색창**에 궁금한 말을 쳐요. 치는 동안 바로바로 목록이 줄어들어요.

- 영어로 쳐도, 한글로 쳐도 돼요. `mcp`, `MCP`, `연결 규격` 모두 같은 카드가 나와요.
- 첫 글자 자음만 쳐도 돼요. `ㅎㄴㅅ` → **하네스**
- 찾은 글자는 노란 형광펜으로 칠해져요.

### 2. 고르기 👆

목록에서 용어를 눌러요.

- **컴퓨터:** 오른쪽에 카드가 열려요.
- **휴대폰:** 카드 화면으로 넘어가요. 돌아올 땐 `← 목록`이나 브라우저 **뒤로 가기**를 눌러요.

### 3. 읽기 📖

카드는 위에서 아래로 읽어요.

| 카드에 있는 것 | 뜻 |
|---|---|
| `WORD 112` | 용어 번호 |
| `출처 02-06` | 이 용어가 나온 교육자료 번호 |
| `입문` `실전` `심화` | 난이도. 입문이 가장 쉬워요 |
| 큰 영어 + 노란 칸 | 용어 이름, 한글 이름, 약어면 영어 전체 이름 |
| **DEFINITION** | 교육자료에 나온 뜻 |
| **쉽게 말하면** | 일상 속 비유로 푼 설명 |
| **예를 들면** | 실제로 쓰는 장면 |
| **연결할 용어** | 같이 알면 좋은 용어. 누르면 그 카드로 가요 |

### 4. 나의 언어로 쓰기 ✏️

**MY NOTE**의 노란 메모장에 이 용어를 내 말로 한두 문장 써요.

- 저장 버튼이 없어요. **쓰는 대로 저장**되고 `저장됨 ✓`이 떠요.
- 남의 설명을 베끼기보다, 친구에게 말해 주듯 써야 오래 기억나요.

### 5. 상태 누르기 ✅

메모장 아래 버튼 세 개로 지금 얼마나 아는지 골라요.

| 버튼 | 언제 누르나요? |
|---|---|
| **알아보기** | 처음 보거나 아직 잘 모를 때 (처음엔 모두 이 상태예요) |
| **다시 보기** | 조금 알겠는데 아직 헷갈릴 때 |
| **마치기** | 내 말로 설명할 수 있을 때 |

> ⚠️ **마치기**는 메모장에 설명을 써야만 눌러져요. 읽기만 하고 "알았다" 하고 넘어가는 걸 막기 위해서예요.

### 6. 진도 보기 📊

| 버튼·표시 | 뜻 |
|---|---|
| `마치기 3 / 144` | 전체 용어 중 마친 개수 |
| **전체 · 알아보기 · 다시 보기 · 마치기** | 그 상태인 용어만 골라 보는 버튼. 아래 숫자는 개수예요 |
| **자료별로 보기** | 교육자료(01-04, 02-01 …)마다 묶어서 보기 |
| **전체 목록** | 묶지 않고 한 줄로 쭉 보기 |
| `▸ 02-04 백엔드와 데이터베이스  3 / 27` | 섹션 이름. 누르면 펼쳐지고(▾) 다시 누르면 접혀요. 오른쪽 숫자는 그 섹션 진도예요 |

### 처음 화면으로 🏠

맨 위 제목 **아, 그게 뭐더라?** 를 누르면 처음 화면으로 돌아와요. 검색어가 지워지고, **전체** 보기에서 섹션이 모두 닫힌 채로 맨 위에 보여요. 기록은 지워지지 않아요.

### 용어 주소 보내기 🔗

카드를 열면 주소 끝에 `#mcp`처럼 용어 이름이 붙어요. 이 주소를 복사해서 보내면 받은 사람도 그 카드가 바로 열려요.

### 키보드 지름길 (컴퓨터)

| 키 | 하는 일 |
|---|---|
| `/` | 검색창으로 바로 가기 |
| `Enter` | 검색 결과 첫 번째 카드 열기 |
| `Esc` | 검색어 지우기 |

### 알아 두세요 💾

- 기록은 **지금 쓰는 브라우저**에 저장돼요. 창을 닫았다 열어도 그대로 있어요.
- 다른 휴대폰이나 다른 브라우저에서는 보이지 않아요. 브라우저 기록을 지우면 사라져요.
- 휴대폰에서 **홈 화면에 추가**하면 앱처럼 '아그뭐' 아이콘으로 열 수 있어요.

## 해결하는 문제

AI 개발을 막 배우는 초보자가, 강의에서 본 용어를 제대로 이해하지 못한 채 넘어가 실습 때마다 다시 찾아본다.

| 막히는 지점 | 이 앱의 대응 |
|---|---|
| 뜻을 잊어버린다 | 용어마다 직접 쓴 설명이 남아서 바로 다시 본다 |
| 설명을 못 한다 | 나의 언어로 설명을 써야 '마치기'로 체크된다 |
| 어디서 봤는지 못 찾는다 | 용어마다 출처(자료 번호)가 붙어 있다 |
| 비슷한 용어가 헷갈린다 | 연결할 용어로 바로 넘어가 비교한다 |

## 기능

- **사전처럼 찾기:** 열자마자 검색창에 커서. 타이핑하는 즉시 결과가 줄어든다. 영어·한글·대소문자 구분 없이, 초성(`ㅎㄴㅅ` → 하네스)으로도 찾는다. `/` 검색 · `Enter` 첫 결과 열기 · `Esc` 지우기
- **용어 144개:** 교육자료 01-04, 02-01 ~ 02-07에 나온 실전 개발·AI 용어. 겹치는 용어는 처음 나온 자료에 하나만 두고 출처를 함께 적었다
- **자료별 섹션:** 섹션을 눌러 펼치고 접는다. 섹션마다 `마친 수 / 전체` 진행률. [전체 목록]으로 한 번에 보기도 된다
- **용어 카드:** 영어 이름, 한글 이름, 약어의 영문 풀네임, PDF 기반 한 줄 뜻, **쉽게 말하면**(초등학생 눈높이 비유), **예를 들면**(실제 장면), 연결할 용어, 난이도(입문·실전·심화)
- **MY NOTE:** 줄 그은 노란 메모장에 나의 언어로 설명을 쓴다. 쓰는 대로 자동 저장되고 `저장됨 ✓`이 보인다
- **상태:** 알아보기 → 다시 보기 → 마치기. 설명이 비어 있으면 '마치기'를 누를 수 없다(공백만 넣어도 막힘). 마친 용어의 설명을 지우면 '다시 보기'로 되돌아간다
- **휴대폰:** 목록 → 카드 → `← 목록` 또는 브라우저 뒤로 가기. 홈 화면에 추가하면 이름이 '아그뭐'로 보인다

## 실행

빌드 없음. 저장소 루트에서 로컬 서버를 띄우고 연다.

```bash
python3 -m http.server 8000
```

→ http://localhost:8000/study-terms-app/

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` · `styles.css` · `app.js` | 구조 · 표현 · 동작 |
| `terms.js` | 처음 만든 기본 용어 20개와 섹션을 붙이는 `addSection()`. 기본 용어도 처음 나온 자료의 섹션에 들어간다 |
| `terms-02-01.js` ~ `terms-02-07.js` | 자료별 용어. 새 강의 용어는 파일 하나를 더한다 |

- 저장: 내 설명과 상태만 브라우저 localStorage에 저장한다. 다른 브라우저·기기와는 공유되지 않는다 (로그인 단계에서 Supabase로 옮길 계획)
- CSS·JS를 고치면 `index.html`의 `?v=` 숫자를 올린다 (브라우저와 GitHub Pages 캐시 때문)

- **배포:** GitHub Pages. 배포 주소에서 성공 조건 3개와 규칙 다시 확인
- **머리말:** 한 줄 제목, 제목과 안내를 잇는 가로선(PC), 안내 문구 '외워야 할 게 있으신가요?', 간격·행간 조정
- **카드:** 노란 메모칸 너비를 가장 긴 용어 기준으로 고정, 셋째 줄은 약어의 영문 풀네임만
- **용어 144개로 확장:** 02-01 ~ 02-07에서 124개 추가, 자료별 섹션과 섹션별 진행률, 예시 보기 버튼 대신 정의 아래에 쉬운 비유와 예시
- **필터 버튼:** 개수를 이름 아래로 옮김 (개수가 1000이 넘어도 옆 여백 유지)
- **노란 메모칸:** 휴대폰에서 칸이 한 글자 폭으로 좁아져 세로로 길어지던 문제 수정(카드가 숨겨진 상태에서 너비를 0으로 재던 버그). PC에서는 칸을 1.5배(340px → 510px)로 넓힘
- **뒤로 가기:** 휴대폰에서 카드를 열면 방문 기록을 남겨, 사파리 뒤로 가기(스와이프 포함)로 목록에 돌아온다. 연결할 용어로 넘어간 뒤 뒤로 가면 이전 카드로. 주소 끝에 `#용어id`를 붙이면 그 카드로 바로 열린다 (예: `#rls`)
- **머리말 라벨:** `TERM NOTES` → `WHAT'S THE WORD AGAIN?`. '팀(Team) 노트'로 읽혀 공용 노트로 오해할 수 있어서, 제목 '아, 그게 뭐더라?'를 영어 입말로 옮긴 표현으로 바꿈
- **휴대폰 제목 크기:** '아, 그게 뭐더라?'를 1.5배(32px → 48px)로
- **용어마다 주소:** PC에서도 카드를 고르면 주소가 `…/study-terms-app/#mcp`처럼 바뀐다. 주소를 복사해 보내면 그 카드가 바로 열린다
- **제목 누르면 처음 화면:** 제목 '아, 그게 뭐더라?'를 누르면 홈으로. 홈 = 필터 '전체' + 자료별 보기 + 섹션 모두 닫힘 + 검색어 없음 + 맨 위. PC에서는 오른쪽 카드 자리도 비워 둔다 (기록은 유지)
- **머리말 라벨 다시:** `WHAT'S THE WORD AGAIN?` → `STUDY TERM NOTES`. 제목과 같은 말을 영어로 반복하는 느낌이고 외국인 대상도 아니라서, 무엇을 하는 곳인지 바로 보이게 (term은 꾸미는 명사라 단수)
- **카드 번호 라벨:** `CONCEPT 006` → `WORD 006`
- **'핵심 20개' 섹션 없애기:** 무엇이 핵심인지 기준이 흔들릴 수 있어서, 20개를 각 용어가 처음 나온 자료 섹션으로 옮김. 01-04에서 처음 나온 GenAI·환각·바이브 코딩·에이전트를 위해 `01-04` 섹션 추가. WORD 번호도 자료 순서대로 001~144로 다시 매김
- **개념 흐름 상자 빼기:** `요청 → 처리 → 응답` 같은 세 칸 상자가 무엇의 흐름인지 알기 어려워서 화면에서 뺌. 쉽게 말하면·예를 들면이 같은 역할을 한다 (데이터는 남김)
