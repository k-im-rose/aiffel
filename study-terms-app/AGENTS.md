# 내 말로 용어장 (공부 용어 앱)

## 개요
AI 개발 입문자가 강의 용어를 내 말로 설명해 보며 익히는 용어장. 사전처럼 검색도 한다. 1인용, 로그인 없음.
- 무엇을 만들지: `PRD.md`
- 어떻게 보일지: `DESIGN.md`
- 어떻게 만들지(기술 선택): `설계.md`
- 용어 원본: `용어집.md` (교육자료 01-01~02-07에서 뽑은 목록)

## 실행
- 빌드 없음. `index.html`을 브라우저로 열면 된다.
- 로컬 서버로 볼 때: `python3 -m http.server 8000` 후 `http://localhost:8000/study-terms-app/` (저장소 루트에서 실행)

## 구조
- `index.html` 구조 / `styles.css` 표현 / `app.js` 동작
- `terms.js` 미리 넣어 둔 용어 데이터 (시작용 20개, id는 저장된 기록과 이어지므로 바꾸지 않는다)
- 저장: 내 설명과 상태만 브라우저 localStorage에 저장

## 규칙
- PRD의 범위(Must)만 만든다. Won't 목록에 있는 기능은 먼저 묻는다.
- 한 번에 하나만 바꾸고, 작동을 확인한 뒤 커밋한다.
- 화면 색·글자·간격은 `DESIGN.md`를 따른다. 노랑(`#FFC629`)은 배경 전용, 글자색이나 선만으로 정보를 전하지 않는다.
- UI 문구는 존댓말로.
- 문서에는 '나·내·내가·우리' 같은 1인칭 주어를 쓰지 않는다. 단, 앱 기능 이름인 '내 설명', '내 말로 용어장'은 예외.
- 외부 라이브러리는 꼭 필요할 때만, 먼저 묻는다.
