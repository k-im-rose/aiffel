# 🍜 냥이의 라면가게

냥이와 함께 손님의 주문대로 라면을 끓이는 3D 요리 게임입니다.
어린 시절 즐겨 하던 플래시 게임 **'슈의 라면가게'**에서 아이디어를 얻었습니다.

- **플레이 주소:** https://k-im-rose.github.io/my-game/nyangi-ramen/
- **저장소:** https://github.com/k-im-rose/my-game
- **대상:** 초등 저학년 (7~9세)
- **조작:** 마우스 클릭 / 터치 / 키보드
- **만든 방법:** 개발 에이전트(Claude Code)와 대화하며 만드는 바이브 코딩

---

## 1. 기획 배경

### 왜 만들었나
라면 끓이기는 아이들도 집에서 한 번쯤 본 익숙한 요리입니다. 그런데 실제로 라면을 끓이려면 **정해진 순서**를 지키고, **어떻게 만들지 기억**해야 합니다.
이 게임은 그 두 가지를 아이들이 놀이로 연습할 수 있도록 기획했습니다.

### 이 게임으로 기르고 싶은 능력

**① 순서대로 해내는 힘 (절차적 사고)**
라면 한 그릇을 만들려면 `물 붓기 → 불 켜기 → 면 넣기 → 스프 넣기 → 토핑 올리기 → 알맞게 익으면 서빙` 순서를 지켜야 합니다.
- 순서를 건너뛰면 결과가 달라집니다. 스프를 빼먹으면 별점이 크게 깎이고, 물이 끓기 전에 면을 넣으면 면이 천천히 익습니다.
- 냄비 위에 "물을 부어 주세요", "불을 켜 주세요"처럼 **다음 할 일**이 계속 떠서, 아이가 혼자서도 순서를 익힐 수 있습니다.
- 하루가 지날수록 토핑이 늘어나 단계가 조금씩 길어집니다. 쉬운 순서부터 시작해 점점 긴 순서를 해내도록 설계했습니다.

**② 주문 기억하기 (작업 기억)**
손님마다 원하는 라면이 다릅니다. 물 양(적게·보통·많이), 익힘(꼬들꼬들·적당히·푹 익음), 토핑 종류를 **기억하고 그대로 만들어야** 합니다.
- 주문서를 보고, 조리하는 동안 그 내용을 머릿속에 담아 둔 채 여러 단계를 진행해야 합니다.
- 1일차에는 토핑이 0~2개로 적게 시작하고, 날이 지날수록 기억해야 할 토핑 개수가 늘어납니다.
- 주문과 다르게 만들면 손님이 "계란이 빠졌어요", "물이 너무 많아요"처럼 무엇이 틀렸는지 바로 말해 줍니다. 아이는 자기가 무엇을 잘못 기억했는지 알 수 있습니다.

> 이 게임은 위 능력을 **연습할 수 있도록 설계**한 것입니다. 실제 능력 향상 효과를 실험으로 검증하지는 않았습니다.

### 7~9세에 맞춘 점
- 하루 영업 시간을 **3분(180초)**으로 넉넉하게 잡았습니다.
- 손님이 기다려 주는 시간을 1일차 기준 **약 66초**로 길게 했습니다.
- 물 양 정답 범위를 넓히고, 면이 천천히 익게 해서 타이밍을 맞추기 쉽게 했습니다.
- **글 대신 캐릭터로 시작합니다.** 첫 화면에는 긴 설명 없이 라면가게 거리 앞에 선 냥이와 '시작하기'·'사용 방법' 버튼 두 개만 있습니다.
- **사용 방법은 냥이가 직접 알려 줍니다.** 냥이가 말풍선으로 한 단계씩(6단계) 설명하고, 각 단계마다 실제 버튼·게이지가 움직이는 그림을 보여 줍니다.
- **실수해도 괜찮게** 만들었습니다. '버리기'로 처음부터 다시 할 수 있고, 목표를 못 채워도 같은 날을 다시 도전할 수 있습니다. 다만 토핑은 한 번 넣으면 뺄 수 없어서, 주문을 잘 보고 넣어야 합니다.
- 물 붓기는 **버튼을 꾹 누르다가 알맞을 때 손을 떼는** 조작이라 아이들이 직관적으로 할 수 있습니다.

| **끝나는 조건** | 하루 3분이 지나면 영업 끝. 목표 매출을 넘기면 다음 날로, 못 넘기면 같은 날 다시 도전 |

## 3. 게임 방법

### 화면 흐름
1. **첫 화면** — 라면가게 거리 앞에서 냥이가 손을 흔들어요. 냥이를 누르면 빙그르 돌거나 폴짝 뛰거나 몸을 흔들며 하트가 떠올라요. 귀엽고 통통 튀는 배경음악이 흐르고, 오른쪽 위 종 아이콘으로 소리를 끄고 켤 수 있어요. '시작하기'를 누르면 냥이가 가스레인지 앞으로 걸어가며 가게가 열려요.
2. **사용 방법** — 첫 화면의 작은 '사용 방법' 버튼을 누르면 냥이가 말풍선으로 6단계를 하나씩 설명해 줘요. 마지막 단계에서 바로 시작할 수 있어요.
3. **영업 화면** — 위쪽에 주방, 아래쪽에 조리 버튼이 있어요.
4. **영업 끝 화면** — 냥이가 다시 앞으로 나와서 오늘 결과를 말해 줘요. 별점, 목표까지 채운 매출 막대, 받은 손님 수가 나오고, 성공하면 '다음 날 영업하기', 아쉬우면 '다시 도전하기' 버튼이 나와요.

### 목표
하루 영업 시간(3분) 안에 **오늘 목표 매출**을 넘기면 성공입니다.
목표는 1일차 20,000원에서 시작해 하루마다 6,000원씩 올라갑니다.

### 라면 끓이는 순서
1. **주문서 보기** — 왼쪽 위 주문서에서 물 양, 익힘, 토핑을 확인해요.
2. **물 붓기 (꾹 누르기)** — '물 양' 게이지가 **분홍 테두리 칸** 안에 들어오면 손을 떼요.
3. **불 켜기** — 냄비 위에 '보글보글!'이 뜨면 물이 끓은 거예요.
4. **면 넣기 → 스프 넣기 → 토핑 올리기** — 스프를 빼먹으면 별점이 크게 깎여요!
5. **서빙하기** — '익힘' 게이지의 검은 막대가 분홍 칸 안에 있을 때 서빙해요. 냄비 위 글씨가 **초록색**으로 바뀌면 바로 그때예요.

### 별점과 돈
| 별점 | 받는 돈 |
|---|---|
| ★★★ | 라면값 전부 |
| ★★☆ | 라면값의 85% |
| ★☆☆ | 라면값의 50% |
| ☆☆☆ | 못 받아요 |

라면값은 기본 3,000원에 주문한 토핑 1개마다 500원이 더해집니다.

### 이기는 요령
- 손님이 오기 전에 물을 '보통'만큼 붓고 불을 켜 두면 시간이 크게 줄어요.
- 물이 끓은 뒤 면을 넣고 **꼬들꼬들은 약 4~8초, 적당히는 약 8~11초, 푹 익음은 약 11~14초** 정도예요.
- 주문서의 손님 인내심 막대가 빨개지기 전에 서빙하세요.

### 조작키
키보드 자판이 **화면 버튼 배치와 똑같은 모양**이 되도록 왼손 가까이에 모았습니다. 각 버튼에 해당 키가 작게 적혀 있어요.

```
화면                                   키보드
[물 붓기][불 켜기][면 넣기][스프]      →  Q  W  E  R
[계란][파][치즈][떡][만두][고춧가루]   →  A  S  D  F  G  H
[버리기]        [서빙하기]             →  Z      Space
```

| 동작 | 버튼 | 키보드 |
|---|---|---|
| 물 붓기 | 물 붓기 (꾹 누르기) | Q (누르고 있기) |
| 불 켜기/끄기 | 불 켜기 | W |
| 면 넣기 | 면 넣기 | E |
| 스프 넣기 | 스프 | R |
| 토핑 | 계란·파·치즈·떡·만두·고춧가루 | A · S · D · F · G · H |
| 냄비 비우기 | 버리기 | Z |
| 서빙 | 서빙하기 | Space |

한글 입력 상태에서도 그대로 동작합니다.

Tab 키로 버튼 사이를 이동해 키보드만으로도 플레이할 수 있습니다.

### 날마다 열리는 토핑
| 날 | 새 토핑 |
|---|---|
| 1일차 | 계란, 파 |
| 2일차 | 치즈 |
| 3일차 | 떡, 만두 |
| 4일차 | 고춧가루 |

## 4. 적용한 게임 전략

1. **난이도 곡선** — 처음엔 토핑 2개로 쉽게 시작하고, 날마다 토핑·목표 금액·손님 요구가 조금씩 늘어납니다.
2. **눈에 보이는 목표** — 게이지 위 분홍 칸으로 정답 범위를 보여 주고, 딱 맞는 순간엔 초록색으로 알려 줍니다.
3. **즉각적인 보상** — 서빙하자마자 별점, 손님의 한마디, 돈이 오르는 효과, 냥이의 기쁜 동작, 효과음이 나옵니다.
4. **다음 할 일 안내** — 냄비 위에 지금 해야 할 일이 계속 표시됩니다.
5. **실수해도 괜찮게, 하지만 신중하게** — 버리기와 같은 날 재도전으로 실패 부담을 줄였습니다. 토핑은 한 번 넣으면 뺄 수 없게 해서 주문을 잘 기억하고 넣도록 했습니다.
6. **빠를수록 더 많은 손님** — 손님이 금방금방 오가서, 빨리 끓일수록 하루에 더 많은 손님을 받을 수 있습니다. '미리 물 끓여 두기' 같은 요령이 생깁니다. 아이들에게 낯선 '팁' 개념은 넣지 않았습니다.
7. **눈과 귀로 느끼는 보상** — 돈을 받으면 동전이 짤랑 소리와 함께 돼지 저금통에 들어가고, 영업 끝에 성공하면 냥이가 방방 뛰며 "와~" 함성이, 실패하면 우는 소리가 나요.
8. **귀여운 분위기** — 분홍 하늘과 구름, 별과 하트, 동물 손님, 알록달록한 상점가로 아이들이 좋아할 분위기를 만들었습니다.
9. **캐릭터가 이끄는 안내** — 첫 화면, 사용 방법, 영업 끝 화면 모두 냥이가 화면 가운데에서 말하는 형식이라 글을 많이 읽지 않아도 흐름을 따라갈 수 있습니다.

## 5. 기술 구성

```
my-game/
├── nyangi-ramen/
│   ├── index.html   # 화면 구조 (주문서, 게이지, 버튼, 시작·결과 화면)
│   ├── styles.css   # 디자인 (색, 글꼴, 배치, 모바일 대응)
│   └── script.js    # 3D 장면과 게임 규칙 (조리 상태, 손님, 별점, 하루 진행)
├── parkour-runner/  # 도시 파쿠르 러너 (별도 게임)
└── README.md
```

- **HTML · CSS · JavaScript** 세 파일로 나누어, 화면(구조)·모양(표현)·규칙(동작)을 따로 고칠 수 있게 했습니다.
- **Three.js**로 3D 장면을 그렸습니다. 냥이와 손님은 이미지 파일 없이 공·원뿔 같은 기본 도형을 조립해서 만들었습니다.
- 글꼴은 Google Fonts의 **Jua**(제목·버튼)와 **Gowun Dodum**(본문)을 썼습니다.
- 효과음과 배경음악은 파일 없이 브라우저의 Web Audio로 직접 만들었습니다. 배경음악은 이 게임을 위해 새로 지은 귀엽고 통통 튀는 짧은 곡(쿵짝 리듬 + 짧게 튕기는 멜로디)이라 저작권 걱정이 없습니다.
- 휴대폰에서는 화면을 처음 터치할 때 소리를 켜고, 아이폰 무음 스위치가 켜져 있어도 게임 소리가 나도록 했습니다.

## 6. 만든 과정

AI와 일하는 리듬인 **계획 → 만들기 → 관찰 → 다시 요청하기** 루프를 여러 번 돌며 만들었습니다.

| 회차 | 내가 한 요청 / 관찰한 문제 | 바뀐 점 |
|---|---|---|
| 1 | "슈의 라면가게와 비슷한 게임을 만들고 싶어. 캐릭터는 사진 속 고양이와 같은 디자인으로 3D로 해줘." (참고 사진 첨부) | 3D 냥이와 주방, 동물 손님, 주문 → 조리 → 서빙 → 정산 흐름이 만들어짐 |
| 2 | (AI가 브라우저로 직접 확인) 한글이 깨지고, 불꽃이 냄비 바닥을 뚫고 보이며, 냥이 몸에 줄무늬 그림자가 생김 | 문서 형식 보완, 냄비를 위로 올리고 받침대 추가, 조명·그림자·수염 굵기 조정 |

## 7. 회고

### 어떻게 진행했나
- **왜 이 게임인가:** '슈의 라면가게'는 어릴 때 재밌게 했던 게임이다. 난이도가 있어서 적당히 어려웠고, 그래서 더 재밌었다.
- **왜 이 캐릭터인가:** 내가 좋아하는 고양이 캐릭터로 만들고 싶었다. 대중적으로 사랑받는 캐릭터라서, 어린이 대상 게임이지만 어른들도 한번 해 보고 싶어질 것 같았다.
- **어떻게 만들었나:** 처음에는 "슈의 라면가게처럼, 이 캐릭터로 3D로 만들어 줘"라고 한 줄로 시작했다. 그다음부터는 직접 플레이해 보고 마음에 안 드는 부분을 하나씩 말로 고쳐 나갔다(6장 '만든 과정' 표의 1~13회차).

### 결과는 어땠나
- 내가 고른 게임(라면 끓이기)의 규칙이 실제로 돌아가는 3D 웹 게임을 완성했고, GitHub Pages로 배포했다.
- 시작 화면 → 사용 방법 → 하루 영업 → 결과 화면 → 다음 날/다시 도전까지 한 바퀴가 동작한다.
- 컴퓨터와 휴대폰 크기 화면 모두에서 플레이할 수 있다.

**처음 플레이해 봤을 때**
- 처음 나온 캐릭터를 보고 '보급형 같다'고 느꼈다. 유명한 캐릭터 사진을 예시로 넣었는데도 똑같이 만드는 건 쉽지 않았다.
- 그래서 "어떤 식으로 대화를 해야 원하는 모습으로 바꿔 나갈 수 있을까?"를 고민하게 됐다. "보급형 같아" → "얼굴이 여전히 달라" + 사진 한 장 더 보내기처럼, 무엇이 다른지 짚어 주고 참고 자료를 더 줄수록 점점 가까워졌다.
- 일단 "만들어 줘"로 시작한 뒤 디테일을 조금씩 고쳐 나가는 재미가 있었다. **AI 개발은 이렇게 하는 거구나** 싶었다.

### 아쉬웠던 점
- **캐릭터와 전반적인 디자인이 아직 보급형 느낌이다.** 기본 도형을 조립해서 만든 3D라서 원본 사진만큼 매끈하고 고급스럽지는 않다.
- **라면 끓이는 소리가 없어서 현실감이 부족했다.** → 회고를 쓰다가 직접 요청해서 물 붓는 소리, 가스 불 소리, 보글보글 끓는 소리를 추가했다.
- **규칙을 내가 먼저 적지 않았다.** 수업에서는 PRD(보이는 것·상태·규칙)를 먼저 쓰고 AI에게 시키라고 했는데, 나는 "슈의 라면가게처럼"이라고만 요청했다. 그래서 하루 100초, 끓는 시간 같은 숫자를 AI가 임의로 정했고, 직접 플레이해 보고 나서야 너무 짧거나 길다는 것을 알았다.
- **대상 연령을 처음에 정하지 않았다.** 중간에 어린이용으로 방향을 바꾸면서 시간·난이도를 다시 조정해야 했다. 처음부터 "누가 하는 게임인지" 정했다면 한 번에 맞출 수 있었을 것이다.
- **AI 혼자서는 '재미'를 판단하지 못했다.** AI는 버튼이 눌리는지, 오류가 없는지는 확인했지만, 기다리는 시간이 지루한지는 내가 직접 해 봐야 알 수 있었다.
- **시간이 더 있었다면** 디자인과 조명을 더 디테일하게 지시해 보고 싶다.

### 느낀 점
- 말 한마디로 이렇게 쉽게 게임이 만들어지는 게 신기했다.
- **내가 지시를 잘할수록 퀄리티와 디테일이 좋아진다**는 것을 직접 경험했다.
- 짧은 시간 안에 이만큼 만들 수 있는 걸 보고, 세상이 참 좋아졌구나 싶었다.
- 만드는 것 자체가 쉬워졌으니, 앞으로는 **퀄리티가 꽤 큰 차별점**이 될 것 같다.

### 마무리 3문장
1. **내 게임을 웹 링크로 처음 열어 봤을 때, 내 컴퓨터에서 열 때와 무엇이 달랐나?**
   예산을 적게 쓴 3D 같은 느낌이었지만, 링크로 열리는 진짜 게임을 보니 좀 더 제대로 다듬으면 재밌게 만들 수 있겠다는 생각이 들었다.
2. **배포 과정에서 AI가 멈추고 나에게 넘긴 단계는 무엇이었고, 왜 사람이 해야 했을까?**
   GitHub 로그인(브라우저에서 코드 입력 후 승인)과 공개 저장소에 올려도 되는지 허락하는 단계였다. **개인 정보 보호, 해킹 방지, 저작권 문제** 때문에 사람이 직접 해야 한다고 생각한다. 내 계정에 들어가는 일과 누구나 볼 수 있게 공개하는 일은 내가 책임지고 결정해야 한다.
3. **이 게임에 딱 한 가지만 더한다면?**
   **테이블을 여러 개 놓고 손님을 동시에 여러 명 받는 기능.** 난이도도 올라가고 더 재밌을 것 같다. 여러 주문을 한꺼번에 기억해야 해서, 이 게임이 기르려는 '주문 기억하기(작업 기억)' 연습에도 잘 맞는다.

### 다음에 더하고 싶은 것
- 테이블을 여러 개 놓고 손님을 동시에 여러 명 받기
- 기억력 연습을 강화하는 '주문서 가리기' 모드 (주문을 잠깐 보여 주고 숨기기)
- 순서를 틀렸을 때 냥이가 힌트를 주는 기능
- 소리로 주문을 읽어 주는 기능 (글을 아직 잘 못 읽는 아이를 위해)
- 디자인과 조명을 더 디테일하게 다듬기
