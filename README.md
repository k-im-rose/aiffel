# 냥이의 라면가게 북적북적

손님 다섯 테이블, 냄비 세 개! 냥이와 함께 여러 손님의 주문을 한꺼번에 해내는 3D 웹 라면 요리 게임입니다.
MODULABS 'AI로 게임 만들기' 과제로 만든 [냥이의 라면가게](https://k-im-rose.github.io/aiffel-nyangi-ramen-shop/nyangi-ramen/)를 바탕으로 한 '여러 손님 + 여러 냄비' 버전입니다.

- 플레이: https://k-im-rose.github.io/nyangi-ramen-rush/
- 기존 1인 손님 버전: https://k-im-rose.github.io/aiffel-nyangi-ramen-shop/nyangi-ramen/
- 대상: 7~9세 / 기획 목표: 순서대로 해내는 힘, 주문 기억하기, 여러 일을 차례로 나눠 하기
- 만든 방식: Three.js r128, 파일 3개(`index.html`, `styles.css`, `script.js`), 설치·빌드 없음

## 기존 1인 버전과 달라진 점

| | 기존 1인 버전 | 북적북적 버전 |
|---|---|---|
| 손님 | 한 번에 한 명 | 테이블 5개(반원 배치)에 손님이 수시로 와서 빈 자리에 앉음. 날이 갈수록 더 자주 옴 |
| 인내심 | 손님 한 명의 막대 | 손님마다 막대가 따로 줄어듦 |
| 냄비 | 1개 | 1일차 2개, 2일차부터 3개. 냄비마다 물·온도·면·스프·토핑·익힘이 따로 진행 |
| 주문서 | 큰 주문서 1장 | 화면 위쪽에 자리 번호별 작은 주문서 최대 5장. 주문서 번호 = 손님 머리 위 번호 |
| 서빙 | 냄비 → 손님 | **고른 냄비**의 라면을 **고른 손님**에게. 별점과 돈은 손님별로 계산 |
| 목표·간격·인내심 | 1인 기준 | 여러 손님 기준으로 다시 계산(아래 참고) |
| 결과 화면 | 받은 손님 | 받은 손님 + 그냥 간 손님 |

그대로 둔 것: 상점가, 냥이(앞치마·요리 모자), 장미 바닥, 종 아이콘(소리 켜기/끄기), 배경음악·효과음, 돼지 저금통, 토핑 취소 불가 규칙, Q W E R / A~H / Z / Space 키 배치, 사용 방법을 냥이가 말풍선으로 설명하는 방식.

## 게임 방법

1. 손님이 테이블에 앉으면 화면 위에 같은 번호의 주문서가 생겨요. (물 양, 익힘, 토핑)
2. **주문서를 눌러** 요리해 줄 손님을 골라요. 고른 손님이 원하는 물 양과 익힘이 게이지에 분홍 칸으로 보여요.
3. **냄비 번호를 눌러** 요리할 냄비를 골라요. (3D 화면의 냄비나 손님을 직접 눌러도 돼요)
4. 물 붓기 버튼을 꾹 눌러 분홍 칸까지 물을 붓고, 불을 켜요.
5. 보글보글 끓으면 면과 스프를 넣고, 주문서에 있는 토핑만 넣어요. 한 번 넣은 토핑은 뺄 수 없어요.
6. 익힘 막대가 분홍 칸에 오면 **서빙하기**. 고른 냄비의 라면이 고른 손님에게 가요.
7. 한 냄비가 끓는 동안 다른 냄비를 시작하면 더 많은 손님을 받을 수 있어요. 3분 안에 오늘 목표 금액을 모으면 다음 날로!

| 날 | 새로 생기는 것 |
|---|---|
| 1일차 | 냄비 2개, 토핑 계란·파 |
| 2일차 | 냄비 3번, 치즈 |
| 3일차 | 떡, 만두 |
| 4일차 | 고춧가루 |

## 조작키

화면 배치와 키보드 배치를 맞췄어요. 위쪽 주문서 = 숫자 줄, 요리 단계 = Q 줄, 토핑 = A 줄, 버리기·냄비 = Z 줄.

| 키 | 하는 일 |
|---|---|
| `1` ~ `5` | 1~5번 주문서(손님) 고르기 **(새 키)** |
| `X` `C` `V` | 1·2·3번 냄비 고르기 **(새 키)** |
| `Q` (꾹 누르기) | 물 붓기 |
| `W` | 불 켜기 / 끄기 |
| `E` | 면 넣기 |
| `R` | 스프 넣기 |
| `A` `S` `D` `F` `G` `H` | 계란 · 파 · 치즈 · 떡 · 만두 · 고춧가루 |
| `Z` | 냄비 비우기 |
| `Space` | 고른 냄비를 고른 손님에게 서빙 |
| `Enter` | 시작 / 다음 날 |

휴대폰에서는 화면의 버튼과 주문서를 누르면 됩니다. 손님이 오면 자동으로 골라지고, 서빙하면 가장 오래 기다린 손님으로 넘어가서 누르는 횟수를 줄였어요.

## 숫자를 정한 근거

하루는 기존과 같이 3분(180초)입니다.

- **손님 간격** `22 − 2 × (날 − 1)`초, 최소 12초 (실제로는 ±20% 무작위): 22 → 20 → 18 → 16 → 14 → 12초.
  라면 한 그릇은 물 붓기·끓이기·면 익히기까지 빨라도 15~20초가 걸려요. 1일차는 냄비 2개로 손님이 오기 전에 한 그릇을 끝낼 수 있게 22초로 시작해, 날마다 조금씩 겹치게 했어요.
  첫 손님은 2초 뒤에 오고, 마지막 25초에는 새 손님이 오지 않아서 마지막 손님도 끝까지 받을 수 있어요.
- **인내심** `95 − 5 × (날 − 1)`초, 최소 65초: 손님이 여러 명이면 내 차례까지 다른 그릇 2~3개를 기다려야 하므로, 1인 버전(45~70초)보다 길게 잡았어요.
- **하루 손님 수** `1 + ⌊(180 − 25 − 2) ÷ 간격⌋`: 7 → 8 → 9 → 10 → 11 → 13명.
- **목표 금액** `하루 손님 수 × 60% × 한 그릇 평균값`(1,000원 단위 반올림).
  한 그릇은 3,000원 + 토핑당 500원이고 별점에 따라 50~100%를 받아요(팁 없음). 평균은 가격의 90%로 잡았어요.
  1일차 13,000원 → 15,000원 → 18,000원 → 20,000원 → 24,000원 → 28,000원.

모든 행동(냄비 고르기, 손님 고르기, 물·불·면·스프·토핑 하나, 서빙)을 하나씩 일정 간격으로만 하는 자동 플레이어로 확인한 결과:

| 행동 간격 | 1일 | 2일 | 3일 | 4일 | 5일 | 6일 |
|---|---|---|---|---|---|---|
| 1.2초 (빠름) | 통과 | 통과 | 통과 | 통과 | 통과 | 통과 |
| 2.5초 (보통) | 통과 | 통과 | 통과 | 통과 | 실패 | 실패 |
| 4초 (느림) | 통과 | 실패 | 실패 | 실패 | 실패 | 실패 |

천천히 하는 아이도 1일차는 성공하고, 날이 갈수록 냄비 두세 개를 번갈아 쓰는 연습이 필요해지도록 맞췄어요.

## 실행

빌드가 필요 없어요. `index.html`을 브라우저로 열거나, 폴더에서 간단한 서버를 띄우면 됩니다.

```bash
python3 -m http.server 8000
```

배경음악과 효과음은 모두 브라우저에서 코드로 만든 소리라 따로 음원 파일이 없어요.
