# 루틴 플래너 (Todo 앱)

## 개요
루틴과 할 일을 추가·완료·조회하는 1인용 앱. 웹 화면은 `npm start`.
- 저장소는 둘: 배포 사이트는 Supabase(실사용 데이터), 로컬 실행은 SQLite `todo.db`.
- 아래 CLI는 **로컬 `todo.db`만** 읽고 쓴다. 배포 사이트의 실제 할 일과 다를 수 있으니, CLI 결과를 실사용 데이터로 여기지 말 것.

## 명령 (CLI)
- 오늘 목록: `node todo.js list`
- 추가: `node todo.js add "<내용>"`
- 완료: `node todo.js done <번호>`
- 오늘 완료 요약: `node todo.js summary`
- 연습·시험할 때는 앞에 `DB_FILE=demo.db`를 붙여 예시 DB를 쓴다.

## 규칙
- 할 일 데이터를 볼 때는 코드나 DB 파일을 직접 읽지 말고 위 CLI를 실행한다.
- UI 문구는 존댓말로.
- README 등 문서에는 '나·내·내가·우리' 같은 1인칭 주어를 쓰지 않는다 (예: '내 수정 요청' → '수정 요청'). 빼면 뜻이 이상해지는 곳만 물어본다.

## 하지 말 것
- `todo.db`(로컬 데이터)를 직접 지우거나 덮어쓰지 말 것.
- `.env`(Supabase 인증 정보)를 읽거나 출력하지 말 것.
