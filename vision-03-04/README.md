# 03-04 선택 과제

> **채점 대상: [A. YOLO 서비스](A-yolo/)**
> B(OCR 표 이미지 문서화)는 추가로 해 본 것이므로 채점에서 빼 주세요.

| 폴더 | 과제 | 실행 위치 | 상태 |
|---|---|---|---|
| [`A-yolo/`](A-yolo/) | 사진을 넣으면 detection 박스와 segmentation 마스크를 보여 주고 저장하는 서비스 | 로컬 (Apple M2 CPU) | 완료 (버스 예제 + 자기 사진) |
| `B-ocr/` | OCR로 표 이미지를 CSV·Markdown 문서로 다시 쓰기 | 미정 | 아직 시작하지 않음 |

**결과 해설 페이지:** [https://k-im-rose.github.io/aiffel/vision-03-04/A-yolo/explainer/](https://k-im-rose.github.io/aiffel/vision-03-04/A-yolo/explainer/)
A의 결과를 교안 개념과 이미지로 연결하고, 자기 사진으로 임계값을 직접 움직여 보는 실험이 들어 있습니다. 같은 내용이 [`A-yolo/explainer/`](A-yolo/explainer/)에 있습니다.

각 폴더의 README에 실행 방법, 실행 위치와 도구 선택 이유, 원본 대조 기록, 확인하지 못한 점을 적었습니다.

입력 자료에는 개인정보나 회사 기밀이 없습니다. 자료의 출처와 공유 조건은 각 폴더의 `manifest.json`과 README에 적었습니다.
