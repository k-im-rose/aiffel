# 데이터 출처와 이용 조건

2026-11-17 기준으로 확인한 내용이다. 법률 검토를 거친 것은 아니며, 개인 학습용 PoC라는 전제로 범위를 좁혔다.

## 뉴스: 매일경제·한국경제 공식 RSS
| 언론사 | 목록 페이지 | 사용한 피드 | 제공 범위 |
|---|---|---|---|
| 매일경제 | https://www.mk.co.kr/rss/ | 경제, 증권, 국제, 기업·경영 | 제목, 요약(평균 약 110자), 링크, 시각 |
| 한국경제 | https://www.hankyung.com/feed | 경제, 증권, 국제, IT, 정치 | 제목, 링크, 기자, 시각 (**요약 없음**) |

- 두 목록 페이지에서 RSS 재사용 범위를 따로 밝힌 문구는 찾지 못했다. 한국경제는 사이트 하단에 별도 "RSS 이용약관" 링크가 있다.
- 그래서 다음 원칙으로 쓴다.
  - 기사 **본문은 가져오지 않는다.** RSS가 주는 제목·요약·링크만 저장한다.
  - 대본은 기사 문장을 옮겨 읽지 않고, 사실을 짧게 다시 설명하며 언론사와 링크를 밝힌다.
  - 만든 MP3는 개인 청취와 과제 시연용이다. 공개 배포(팟캐스트 플랫폼 등)는 하지 않는다.
  - 저장소에는 평가에 쓴 30건의 제목·요약·링크만 둔다. 수집 원본 전체(`data/raw/`)는 올리지 않는다.
- 상용 서비스로 넓히려면 언론사와 콘텐츠 이용 계약 또는 뉴스 API(제휴) 검토가 필요하다.

## 공시: OpenDART
- https://opendart.fss.or.kr/ (금융감독원 공식 Open API, 개인 인증키 발급)
- 공시는 공개 정보다. 일일 호출 한도가 있으므로 등록 종목만 조회한다.
- 인증키는 `.env`에만 두고 저장소에 올리지 않는다.

## 음성: edge-tts
- 라이브러리 https://github.com/rany2/edge-tts (LGPLv3)
- Microsoft Edge 읽어주기 기능을 부르는 비공식 방식이다. 개인 학습·시연 용도로만 쓴다. 배포 시에는 Azure AI Speech 같은 공식 API로 바꾼다 ([model_selection.md](model_selection.md) 2절).
- 결과 음성은 AI가 만든 음성이며, 실제 인물이 아니다. 대본 첫머리에 이를 밝힌다.

## LLM: Anthropic Claude API
- 기사 제목·요약과 사용자가 적은 관심 종목·투자 논리를 보낸다. 계좌번호, 보유 수량, 평단가, 개인 식별 정보는 보내지 않는다.

## 개인정보·보안
- `profiles/my_profile.json`(실제 관심 종목)은 공개해도 되는지 사용자가 정한다. 공개하지 않으려면 `.gitignore`에 넣고 `fixtures/demo_profile.json`으로 시연한다.
- API 키는 `.env`, 예시는 `.env.example`.

## 해외 소스 (2026-11-17 추가)
자세한 조사: [foreign_sources.md](foreign_sources.md)
- **CNBC RSS:** 사이트 약관상 개인·비상업 이용. 제목, 한 문장 요약, 시각, URL만 저장한다.
- **Spaceflight News API:** 무료, 키 없음. 기사 권리는 원 매체에 있고, 원 매체명은 보존한다.
- **연결하지 않은 소스:**
  - Bloomberg RSS: 약관이 보관·데이터베이스 구축을 금지한다.
  - Alpha Vantage: 뉴스 기능이 Premium이다.
- **번역:** 방송에 쓰는 해외 기사만 Haiku로 번역하고, 원문 제목과 URL은 리포트에 함께 남긴다.
