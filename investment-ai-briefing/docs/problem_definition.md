# 문제 정의서

## 1. 도메인
개인 투자자의 정보 모니터링이다. 보유 종목과 아직 사지 않은 관심 종목에 대해 경제 뉴스, 기업 공시, 거시경제(미국 금리·환율·정책) 변화를 매일 따라가고, 그중 내 투자 논리에 영향을 주는 것만 골라 판단에 쓰는 일이다.

작성자는 투자 교육 회사에서 운영 코치로 일하며 매주 "뉴스 → 무슨 일 → 왜 → 영향 산업 → 2·3차 수혜 기업 → 주의할 점" 틀로 라이브 수업을 진행했고, 지금도 코스닥 중소형 성장주에 직접 투자한다. 현재는 AI 과정을 들으며 투자 정보를 챙길 시간이 크게 줄었다.

## 2. 현재 방식과 문제
| 단계 | 지금 하는 방식 | 막히는 지점 |
|---|---|---|
| 수집 | 포털·경제지 앱을 직접 열어 보거나 Google 키워드 알림 메일을 받는다 | 하루 경제지 두 곳 RSS만 해도 400건이 넘는다 (2026-11-17 실측 439건) |
| 선별 | 알림 메일의 기사 제목을 하나씩 보고 내 종목과 관련 있는지 판단한다 | 키워드가 들어간 무관한 기사가 많고, 종목명이 안 나오는 산업·정책 기사는 놓친다 |
| 이해 | 관련 기사를 열어 읽고 내 종목에 어떤 영향인지 정리한다 | 시간이 없으면 이 단계까지 가지 못한다 |
| 공시 | DART에서 종목별로 따로 확인한다 | 뉴스와 따로 놀아서 자주 빠뜨린다 |

**수집 단계에서 확인한 사실:** 2026-11-17 매일경제·한국경제 RSS 9개 피드의 기사 439건 중 등록한 코스닥 4종목의 이름이 나온 기사는 **0건**이었다. 일반 뉴스 피드는 그날 많이 쓰인 대형 이슈 중심이라, 중소형주 투자자는 종목별로 따로 찾아야 한다. 같은 날 한국경제 검색으로는 이 종목들의 수주공시 기사가 바로 나왔다.

**실제로 겪은 실패:** Google 키워드 알림을 써 봤지만 무관한 기사가 너무 많이 와서 결국 사람이 다시 분류해야 했고, 몇 주 뒤에는 알림 메일 자체를 열지 않게 됐다. 정보는 충분한데 선별 비용 때문에 정보 소비를 포기한 상태다.

03-09 교안의 병목 유형으로는 **분류와 배분**(건수가 많다)이 핵심이고, 결과를 듣기 좋은 형태로 바꾸는 부분은 **입력과 전사**의 반대 방향(글 → 음성)이다.

## 3. 개선 가설
> 종목명만 보는 키워드 매칭 대신, 종목별 **투자 논리**와 **거시경제 관심사**를 함께 준 LLM이 기사를 판정하면 무관한 기사는 줄이면서 종목명이 안 나오는 산업·정책·거시 기사는 놓치지 않는다. 남긴 기사를 근거 링크와 함께 두 진행자가 설명하는 팟캐스트로 만들면, 화면을 열지 않고도 출퇴근길에 그날의 판단 재료를 들을 수 있다.

AI를 넣는 단계는 두 곳이다.
1. **선별(핵심):** 기사 제목·요약 + 투자 프로필 → 관련 / 무관 / 판단 보류, 연결 방식(직접·간접·거시), 근거 문구
2. **전달:** 선별된 기사와 공시 → 두 진행자 대화 대본 → 음성(TTS) → MP3

## 4. 대상 사용자
- **1차:** 작성자 본인. 보유·관심 종목 몇 개와 투자 논리가 분명하지만 매일 뉴스를 훑을 시간이 없는 개인 투자자.
- **확장:** 같은 상황의 개인 투자자. 프로필 파일만 바꾸면 각자의 종목·논리로 돌아가게 설계한다.
- **다른 업무로 옮기면:** 경쟁사 모니터링, 정책·규제 변경 추적, 시장 조사처럼 "많은 문서 중 우리 맥락에 맞는 것만 골라 근거와 함께 전달"하는 일 전반. 프로필 = 회사의 관심 기업·제품·이슈 목록으로 바뀐다.

## 5. 성공 기준 (모델 실행 전에 고정)
측정 방법과 데이터 구성은 [evaluation_plan.md](evaluation_plan.md)에 있다.

| # | 기준 | 목표 |
|---|---|---|
| 1 | AI 선별의 **재현율** (사람이 관련이라고 한 기사 중 AI가 남긴 비율) | 90% 이상 |
| 2 | AI 선별의 **정밀도** (AI가 남긴 기사 중 실제 관련 비율) | 80% 이상 |
| 3 | 키워드 기준선 대비 | 오탐 수가 줄고, 누락 수는 키워드 이하 |
| 4 | 처리 시간 | 같은 30건을 사람이 고르는 시간보다 짧다 (실측 비교) |
| 5 | 근거 추적성 | 대본에 들어간 사실 100%가 원문 링크로 이어진다. 근거가 없는 내용은 빼거나 "확인 필요"로 표시한다 |
| 6 | 끝까지 동작 | 프로필 입력 → 수집 → 선별 → 대본 → 두 목소리 MP3까지 한 번에 실행된다 |

누락(관련 기사를 버림)은 오탐(무관한 기사를 남김)보다 위험하게 본다. 오탐은 듣는 사람이 흘려들으면 되지만, 누락은 판단 재료 자체가 사라지기 때문이다.

## 6. 범위
- **이번에 한다:** 수동 종목 등록(보유·관심), 매경·한경 RSS와 OpenDART 실제 수집, AI 선별, 두 진행자 팟캐스트 MP3, 키워드 방식 대비 검증
- **이번에 안 한다 (확장 계획):** 매일 자동 발송, 증권사 계좌 연동, 여러 사용자 계정, 사업보고서 심층 분석, 매매 추천
- **하지 않는다 (원칙):** 매수·매도 추천, 주가 예측, 주문 실행
