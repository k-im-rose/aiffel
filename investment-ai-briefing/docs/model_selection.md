# 모델 선정

조건이 먼저 후보를 좁혔다.
- 입력이 **한국어** 경제 기사이고, 판정에 "투자 논리"라는 긴 맥락을 함께 넣어야 한다 → 한국어를 잘 읽고 지시를 길게 따르는 LLM
- 결과를 프로그램이 그대로 받아야 한다 → **구조화 출력**(정해진 JSON 형식) 지원
- 데이터는 공개 기사 제목·요약과 사용자가 직접 쓴 관심 종목뿐이다 → 외부 API로 보내도 되는 수준 (계좌번호·수량·평단은 받지 않는다)
- 기사가 하루 수백 건이다 → 건당 비용이 낮아야 한다

## 1. 선별(분류) 모델

| 후보 | 장점 | 단점 | 판단 |
|---|---|---|---|
| 키워드 매칭 | 빠르고 공짜, 설명이 쉽다 | 문맥을 모른다 (지금 방식의 한계 그 자체) | **기준선 A** |
| 임베딩 유사도 (예: bge-m3, 03-06·03-09에서 본 방식) | 로컬 실행, 빠름 | "기사 ↔ 투자 논리" 유사도만 나오고, 왜 관련인지·불확실한지를 말하지 못한다. 임계값을 따로 정해야 한다 | 이번엔 제외, 대량 1차 필터로 확장 후보 |
| 로컬 소형 LLM (Ollama 등) | 비용 0, 데이터가 밖으로 안 나감 | 이 맥에 설치돼 있지 않고, 한국어 경제 문맥 판단력이 낮다. 이틀 일정에 설치·튜닝 부담 | 제외 (한계 문서에 기록) |
| **Claude Haiku 5.5** | 저렴(입력 $0.10 / 출력 $0.50 per 1M 토큰), 구조화 출력, 한국어 | 상위 모델보다 판단이 얕을 수 있다 | **후보 B1 (기본값)** |
| **Claude Sonnet 5.5** | 판단력이 더 좋다 | Haiku의 약 20배 가격 (입력 $2 / 출력 $10) | **후보 B2 (비교용)** |

### 비용 어림 (실측 전 추정)
기사 15건을 한 번에 보내면 입력 약 3,000토큰, 출력 약 2,500토큰이다.
- Haiku 5.5: 30건 평가 1회 ≈ $0.003, 하루 450건 ≈ $0.04
- Sonnet 5.5: 30건 평가 1회 ≈ $0.06, 하루 450건 ≈ $0.9

실측값은 `evaluation/runs/*/metrics.json`의 `llm_cost_usd`에 남고, 결과는 README 4절에 집계로 정리했다(원본 평가 문서는 비공개).

### Haiku 하나로 충분한가
Haiku로 선별과 대본 생성을 모두 해 보고, Sonnet과 같은 평가셋에서 비교한다. 성공 기준(재현율 90%, 정밀도 80%)을 Haiku가 넘으면 Haiku만 쓴다. 대본은 사용자가 들어 보고 정성 비교한다.

### API 키가 없을 때의 대체 수단
| 방법 | 내용 | 한계 |
|---|---|---|
| **Claude Code CLI (`claude -p`)** | 같은 Claude 모델을 개인 구독으로 부른다. 기본 지시문·도구·설정을 모두 끄고(`--system-prompt`, `--tools ""`, `--setting-sources ""`) 구조화 출력(`--json-schema`)을 써서 API와 거의 같은 조건으로 맞췄다 (테스트 호출 입력 약 1,300토큰) | 호출마다 CLI 시작 시간(수 초)이 붙어 처리 시간 측정이 API보다 불리하다. 개인 도구라 서비스 배포에는 못 쓴다 |
| 저장된 결과 재생 (`--mode sample`) | 키 없는 리뷰어가 저장된 선별 결과·대본·MP3로 흐름을 확인한다 | 모델을 새로 돌린 것은 아니다. README에 이 차이를 명시한다 |
| 로컬 LLM | Ollama + 한국어 모델 | 위 표 참고. 확장 후보 |

코드에서는 `--backend auto`가 Claude Code CLI(구독)를 쓴다. 종량제 API는 비용 원칙상 `ALLOW_PAID_API=1`과 `ANTHROPIC_API_KEY`를 둘 다 직접 켠 경우에만 자동 선택된다 (`app/llm.py`).

## 2. 음성(TTS)

| 후보 | 한국어 두 목소리 | 비용·키 | 이용 조건 | 판단 |
|---|---|---|---|---|
| **edge-tts** (Microsoft Edge 읽어주기 서비스) | 있음: SunHi(여), InJoon(남), Hyunsu(남) | 무료, 키 없음 | 라이브러리는 LGPLv3. 단, Microsoft의 **공식 공개 API가 아니라** Edge 브라우저 기능을 부르는 비공식 방식이다. 개인 학습·시연 용도로만 쓰고, 서비스로 배포할 때는 아래 공식 API로 바꿔야 한다 | **이번 PoC 기본값** |
| Azure AI Speech (공식) | 같은 음성 계열 | 무료 등급 있음, Azure 키 필요 | 공식 약관, 상업 이용 가능 | 배포 시 1순위 대안 |
| Google Cloud TTS | 한국어 여러 음성 | 무료 등급 있음, GCP 키 필요 | 공식 약관 | 대안 |
| OpenAI TTS | 다국어 음성 | 유료, 키 필요 | 공식 약관, AI 음성임을 알려야 함 | 대안 |
| 로컬 TTS (MeloTTS 등) | 한국어 화자 1명인 경우가 많음 | 무료 | 오픈소스 라이선스 | 두 목소리 구분이 어려워 제외 |

MP3는 ffmpeg 없이 화자별 MP3 조각을 순서대로 이어 붙인다 (같은 형식의 MP3 프레임이라 재생에 문제가 없다). 이어 붙인 결과가 재생기에서 문제가 생기면 ffmpeg로 바꾼다.

## 3. 사용한 실제 설정
실행할 때마다 모델 ID, 백엔드(api/cli), 토큰, 비용, 시간을 결과 파일에 함께 저장한다. 이 표는 실험 뒤에 채운다.

| 단계 | 모델 | 백엔드 | 설정 |
|---|---|---|---|
| 선별 | **Claude Haiku 5.5** (`claude-haiku-5-5`) | cli (API 키 없음) | effort low, 평가는 15건씩, 실제 실행은 25건씩 5개 동시 호출. 응답에서 빠진 기사는 한 번 더 묻는다 |
| 대본 | **Claude Sonnet 5.5** (`claude-sonnet-5-5`), Haiku로도 가능 | cli | effort medium, 구조화 출력(JSON Schema) |
| 음성 | edge-tts 7.3.1 | 로컬에서 Microsoft 서비스 호출 | ko-KR-SunHiNeural / ko-KR-InJoonNeural |

## 4. 실험 결과로 정한 것 (2026-11-17)

### 선별: Haiku
같은 30건, 같은 지시문으로 비교했다 (README 4절, 원본 평가 문서는 비공개).

| 모델 | 재현율 | 정밀도 | 유형 일치율 | 30건 시간 | 30건 비용 |
|---|---|---|---|---|---|
| Haiku 5.5 (3회) | 74% | 95% | 53~57% | 80~101초 | 약 $0.013 |
| Sonnet 5.5 | 74% | 95% | 47% | 53초 | 약 $0.133 |

- **Sonnet이 낫지 않았다.** 관련/무관 판정은 기사 단위까지 같았고, 유형 일치율은 오히려 낮았다.
- **틀린 원인은 모델 크기가 아니었다.** 지시문과 라벨 정의의 문제였다 (README 4-2). 그래서 10배 비싼 모델로 바꿀 이유가 없다.
- **실제 하루치:** 460건을 Haiku로 판정하는 데 186초, 약 $0.13이 들었다.

### 대본: Haiku도 되지만 Sonnet을 기본으로
같은 선별 기사 12건으로 두 모델의 대본을 만들었다 (`outputs/sample/script.md`와 `script_haiku.md`).

| 항목 | Haiku 5.5 | Sonnet 5.5 |
|---|---|---|
| 대사 수와 길이 | 44줄, 약 6분 43초 | 47줄, 약 8분 |
| 12건 모두 인용 | 예 | 예 |
| 없는 기사 id 인용 | 0 | 0 |
| 매수·매도 권유 표현 | 0 | 0 |
| 확인되지 않은 관계 처리 | "직접 거래 관계는 확인되지 않았다"로 말함 | 같음 |
| 대화 흐름 | 설명 위주, 질문이 적음 | 질문과 답이 번갈아 나와 듣기 쉬움 |
| 시간 / 비용 (CLI) | 94초 / 약 $0.013 | 43초 / 약 $0.10 |

- **Haiku 하나로 끝까지 가능한가:** 그렇다. 근거·금지 규칙은 Haiku도 모두 지켰다.
- **Sonnet을 기본으로 둔 이유:** 사람이 매일 듣는 결과물이라 대화의 자연스러움을 우선했다. 하루 1회 호출이라 비용 차이는 약 $0.09다.
- **바꾸는 법:** `--script-model haiku`로 바꿀 수 있다.
- **자동 점검의 한계:** "숫자가 있는데 출처가 없는 대사"에는 질문 대사가 섞여 잡힌다(오탐). 최종 사실 확인은 사람이 출처 링크로 한다.
