# 비용 원칙과 AI 호출 비용의 의미

> 2026-11-18 기준. 코드와 저장된 실행 기록(`run.json`, 평가 `metrics.json`)만 읽고 정리했다. 확인을 위해 새 AI 호출은 하지 않았다.

## 1. 비용 원칙 (작성자 결정)
그내종을 개발하고 운영하는 과정에서 **별도의 비용이 생기지 않게** 한다.
- 유료 API 호출, 추가 결제가 필요한 AI 테스트, 유료 데이터 수집 서비스를 쓰지 않는다.
- 유료 서버·데이터베이스 계약, 유료 음성 생성 서비스를 쓰지 않는다.
- 무료 한도를 넘으면 자동으로 요금이 나가는 방식을 쓰지 않는다.
- 금액이 아무리 작아도 사전 동의 없이 실제 비용이 생기는 작업은 실행하지 않는다.
- 무료로 만들거나 운영하기 어려운 기능은 억지로 개발하지 않고, 제약과 대안을 문서에 남긴다.

**코드에 넣은 안전장치:** `ANTHROPIC_API_KEY`가 환경에 있어도 종량제 API는 자동으로 고르지 않는다. 키와 `ALLOW_PAID_API=1`을 **둘 다** 직접 켠 경우에만 `api` 백엔드를 쓴다 (`app/llm.py`, 테스트 `tests/test_llm_backend.py`). 기본값은 Claude Code CLI(구독)다.

## 2. AI 호출 비용의 실제 의미

| 질문 | 확인한 답 | 근거 |
|---|---|---|
| 실제 Anthropic API(종량제)를 쓰고 있나 | **아니다.** 저장된 모든 실행(1차 평가 4회, 데모 v2~v4)의 백엔드가 `cli`다. 이 환경에는 `.env`와 API 키가 없다 | `evaluation/runs/*/metrics.json`의 `backend`, `demo/outputs/*/run.json`의 모델 표기 "(Claude Code CLI)" |
| Claude 구독 사용량을 쓰나 | **그렇다.** `claude -p`(Claude Code CLI)를 로그인된 개인 계정으로 부른다. 호출은 그 계정의 사용량 한도(주간 한도 포함)에서 소진된다 | `app/llm.py`의 cli 백엔드 |
| `run.json`의 `cost_usd`는 실제 청구액인가 | **청구액이 아니라 API 가격으로 환산한 추정값이다.** cli 백엔드는 CLI가 돌려주는 `total_cost_usd`를 그대로 적는다(코드로 확인한 부분). 이 값은 CLI가 토큰 사용량으로 계산한 추정치이며 구독 계정에 청구되는 금액이 아니다(Claude Code의 동작에 대한 설명이고, 이 저장소만으로는 계산식을 확인할 수 없다). api 백엔드를 쓸 때는 코드 안의 단가표(`PRICES`: Haiku 입력 $0.10·출력 $0.50, Sonnet 입력 $2·출력 $10, 100만 토큰당)로 계산한다 | `app/llm.py` |
| 현재 어떤 모델을 어떤 인증으로 부르나 | 선별: Haiku 5.5. 편집·대본·사실 검증·원문 대조·웹 보조 내용: Sonnet 5.5. 인증은 모두 **로그인된 Claude Code CLI 세션**이며 이 저장소에는 키나 토큰이 없다 | `app/pipeline.py` 기본 옵션(`--select-model haiku`, `--edit-model/--script-model/--check-model sonnet`) |
| 매일 자동 실행하면 별도 API 비용이 나가나 | 구독(CLI)으로 돌리면 **별도 API 청구는 없다.** 대신 구독 사용량이 매일 소진된다. 구독 한도를 넘었을 때 추가 사용량 결제를 켜 두었는지는 이 저장소에서 확인할 수 없으니 **계정 설정에서 직접 확인**해야 한다. API 키를 쓰는 방식으로 바꾸면 그때부터 종량제 요금이 나간다 (위 안전장치로 막아 둠) | 위 코드와 기록 |

**기록된 환산 비용 (참고용, 청구액 아님)**
- 선별 30건: Haiku 약 $0.012~0.016, Sonnet 약 $0.133 (`docs/model_selection.md`)
- v4 실행(약 14분): 편집 약 $0.12, 대본 약 $0.18, 원문 대조 약 $0.38 등 (`demo/outputs/20261117_v4/run.json`)

## 3. 무료로 운영하기 위한 선택지 검토

| 영역 | 현재 | 무료 범위에서의 판단 |
|---|---|---|
| LLM | Claude 구독 + CLI | **유지.** 추가 청구 없음. 사용량 한도 안에서만 쓴다. 선별은 Haiku로 충분했고(Sonnet이 더 낫지 않았음) 편집·대본·검증은 Sonnet이라, 구독 한도를 아끼려면 단계별로 Haiku로 낮춘 품질 비교가 필요하다 |
| 무료 API 등급 | 사용 안 함 | 제공사별 무료 한도·약관·한도 초과 시 과금 여부를 **아직 확인하지 않았다.** 도입 전에 "한도 초과 시 자동 과금되지 않는다"가 확인되는 경우에만 후보로 둔다 |
| 오픈소스·로컬 모델 | 사용 안 함 | 비용은 없지만, 1차 평가 때 한국어 경제 문맥 판단력과 구조화 출력 품질이 낮을 것으로 보고 제외했다(`docs/model_selection.md`). 선별(분류) 단계만 로컬 모델로 시험해 볼 가치는 있으나 품질은 **미검증**이다. 편집·대본·출처 대조는 품질 위험이 커서 권하지 않는다 |
| 음성 | edge-tts (무료, 키 없음) | 비공식 서비스라 개인용으로만 쓴다. 공식 무료 등급이 있는 TTS는 한도 초과 시 과금 여부 확인 전에는 쓰지 않는다 |
| 뉴스·공시·종목 목록 | 무료 RSS, OpenDART(무료 키), SEC(키 없음) | 모두 무료. 유료 뉴스 API는 쓰지 않는다 |
| 서버·DB | 로컬 파일(JSON), 로컬 서버 | 유료 서버·DB 계약 없이 로컬 저장을 유지한다. 외부 공개 배포는 인증이 생기기 전까지 하지 않는다 |
| 매일 자동 실행 | 미등록(`deploy/install_launchd.sh` 준비) | 맥의 `launchd`는 무료다. 맥이 켜져 있어야 한다. 클라우드 예약 실행은 비용이 생길 수 있어 하지 않는다 |

**무료로 하기 어려운 것과 대안**
- **외부에서 접속하는 웹사이트:** 인증을 직접 만들어야 하고 무료 호스팅은 한도·약관 확인이 필요하다. 대안은 집 안 와이파이에서 같은 맥을 쓰거나(`--host 0.0.0.0`, 시험용), 보고서와 음성을 이미 쓰는 개인 저장 공간(iCloud 폴더 등)으로 복사해 아이폰에서 재생하는 것이다.
- **하루 여러 번 생성·품질 비교 시험:** 모두 구독 사용량을 쓴다. 사용량이 부족한 주에는 시험을 미룬다.
- **집중 분석 전후 비교:** AI 호출이 필요해 구독 사용량을 쓴다. 제출 이후, 사용량에 여유가 있을 때 진행한다.
