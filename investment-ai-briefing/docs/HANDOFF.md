# 인수인계: 그내종 UI/UX 디자인 작업

## 1. 프로젝트 경로
- 로컬: `~/에이펠/investment-ai-briefing` (Git 저장소 루트는 한 단계 위 `~/에이펠`, 브랜치 `investment-ai-briefing`)

## 2. 현재 구현된 화면과 기능 (로컬에서 실제 동작)
| 화면 | 주소 | 기능 |
|---|---|---|
| 메인 | `/` | 최신 승인 보고서(발행일·핵심 뉴스 제목·요약·오디오 길이·보고서 읽기), 프로필 요약, 지난 브리핑(날짜별 승인판만), 미완료 점검 항목 |
| 일일 보고서 | `/report/<run_id>` | 01 브리핑 오디오(배속)·출처 대조 결과 / 02 주요 뉴스(확인된 사실·근거 수준·확인 불가·AI 해석) / 03 그래서 내 종목은? / 04 방송에 담지 못한 뉴스 / 05 경제 개념 / 06 퀴즈 / 07 메모 / 08 점검 목록·AI 추천 |
| 마이페이지 | `/mypage` | 프로필 편집, 날짜별 메모, 완료·미완료 점검 항목(중요 표시), 지난 브리핑, 계정(자리만) |
| 최초 프로필 설정 | `/onboarding` | 종목·이유·키워드·위험·AI에게 확인받고 싶은 것. 프로필에 종목이 없으면 메인에서 이동 |
| 개발·평가 기록 | `/records` | 승인판이 아닌 실행과 승인 관문 미통과 이유 |
| 스타일 가이드 | `/styleguide` | 디자인 토큰과 컴포넌트 견본 |
| 로그인 | `/login` | **화면 시안만.** 입력 비활성, 아무것도 보내지 않음 |

| 로그인 시안 | `web/login.html` | — |

- 서버: `app/web_server.py` (내보내는 파일은 `STATIC` 목록에 있는 것만. 새 파일을 만들면 여기에 등록해야 열린다)
- 이전 한 페이지 화면(보존용, 서버가 내보내지 않음): `web/v1_single_page/`

## 4. 디자인 시스템
- 공통 스타일: `web/style.css` (1절 토큰 → 5절 컴포넌트 → 7절 좁은 화면)
- 정리 문서: `docs/design_system.md` (토큰, 컴포넌트와 쓰이는 곳, 레퍼런스 적용 순서)
- 견본: `web/styleguide.html` → `/styleguide`
- 화면 HTML에는 인라인 스타일이 없다. 시각 변경은 `style.css`에서 한다.

## 5. 로컬 서버 실행
```bash
cd ~/에이펠/investment-ai-briefing
.venv/bin/python -m app.web_server --data demo
```
- http://127.0.0.1:8777 (가상 데모 프로필). 데모 승인판 보고서: `/report/20261117_v3`
- `--data real`은 실제 비공개 프로필이다. 디자인 작업에는 쓰지 않는다.

## 6. 확정한 디자인 원칙
- 컬러: 화이트 `#FFFFFF`, 차콜 `#222222`, 단일 포인트 테라코타 `#B8755B`. 그 밖에는 무채색 회색만, 다른 유채색 없음
- 명조체 중심 타이포그래피 (현재 Noto Serif KR은 임시)
- 충분한 여백, 얇은 구분선. 카드형 UI·그림자·둥근 모서리·장식 아이콘 없음. 과한 볼드 없음
- 기사 본문은 가독성 우선 (본문 폭 680px, 줄간격 1.85)
- 모션은 숫자·그래프에만, 짧게 (동작 줄이기 설정 존중)
- 일일 보고서는 위에서 아래로 읽는 세로 한 줄 구조. 섹션을 나란히 두지 않는다
- 브랜드: '그내종.'을 크게, 아래 '그래서 내 종목은?', 오른쪽 소개 두 줄("투자자의 일일 경제 브리핑, / 시장을 읽고 내 투자로 연결하는 기록."), 세로 구분선 없음
- 아이폰 폭(375px)에서 가로 스크롤 없음

## 7. 아직 구현되지 않은 기능
- 디자인 레퍼런스 반영 (글꼴·세부 배치)
- 로그인·회원가입·다중 사용자·계정 설정 (설계: `docs/auth_design.md`)
- 외부 배포(HTTPS), 07:35 자동 실행 등록, 비공개 팟캐스트 피드 연결
- 지난 브리핑 달력 선택, 퀴즈 답 기록
- 맞춤법 점검, 공시·공식 통계 대조, 복합 수 표기 환산

## 8. 주의 사항
- **화면 구조·데이터 연동 유지:** HTML의 `id`, JS, API 경로(`/api/...`), `briefing.json` 모양을 바꾸지 않는다. 디자인은 `style.css`와 클래스 규칙으로만 바꾼다.
- **동작 상태 표시 유지:** 각 섹션의 "동작 상태" 문구와 "AI 해석(사실이 아닌 추론)", "확인 불가", "개발·평가 기록" 표시는 지우지 않는다.
- **비공개 데이터:** `profiles/my_profile.json`, `userdata/`, `private/`, `outputs/`, `evaluation/`, `data/raw/`, `.env`는 커밋하지 않는다(MP3는 `demo/outputs/`의 가상 프로필 데모 음성만 공개하고, 실제 프로필 음성은 `outputs/`라 제외된다) (`.gitignore`). 디자인 작업은 `--data demo`로만 한다.
- **보존 기록:** `demo/outputs/20261117/`, `demo/outputs/20261117_v2/`, `docs/failure_cases_demo.md`, 평가 결과는 수정·삭제하지 않는다.
- **커밋 전 검사:**
  ```bash
  .venv/bin/python scripts/privacy_check.py
  ```
  ```bash
  .venv/bin/python -m tests.test_links
  ```
- 매수·매도 권유, 주가 예측 표현을 넣지 않는다.
