# 정보 소비 경험 평가 계획 (아직 측정 전)

1차 평가는 **정보 선별**이 맞는지(키워드 대 AI의 정밀도·재현율)를 봤다 ([evaluation.md](evaluation.md)).
그런데 이 프로젝트가 풀려는 문제는 두 가지다.

| 문제 | 해결 방법 | 지금까지 검증한 것 |
|---|---|---|
| 정보 선별의 부담 | AI가 투자 논리 기준으로 고른다 | 30건 라벨 평가 (1차) |
| 정보 소비의 부담 | 음성 브리핑으로 아침 준비·이동 중에 듣는다 | **아직 없음.** 이 문서가 계획이다 |

## 1. 시간을 어떻게 셀 것인가

**팟캐스트 청취 시간은 절약된 시간이 아니다.** 11분짜리 브리핑을 들으면 11분이 든다. 바뀌는 것은 그 11분을 **다른 일과 함께 쓸 수 있느냐**다.
- 기존: 화면을 보며 검색하고 읽는 시간. 다른 일을 할 수 없는 **전용 시간**이다.
- 새 방식: 씻기, 옷 입기, 걷기, 대중교통 같은 기존 일과와 **겹쳐 쓰는 시간**이다.

그래서 시간을 세 칸으로 나눠 기록한다.

| 칸 | 뜻 | 측정 방법 |
|---|---|---|
| A. 전용 시간 (기존) | 하루 뉴스 확인에 화면을 보며 쓴 시간: 검색, 알림 메일 훑기, 기사 읽기, 관련 여부 판단 | 기존 방식으로 3일. 시작·끝 시각 기록 |
| B. 병행 청취 시간 (새 방식) | 다른 일을 하며 브리핑을 들은 시간 | 7일. 들은 시각, 함께 한 일, 끝까지 들었는지 |
| C. 추가 전용 시간 (새 방식) | 브리핑을 듣고 나서 원문·리포트를 따로 열어 본 시간 | 7일. 같은 방식으로 기록 |

**판단 기준:** 새 방식의 전용 시간(C)이 기존 전용 시간(A)보다 줄었는가.
- 참고값: 1차 평가에서 30건에 라벨을 다는 데 사람이 **12분**을 썼다. 하루 수집량은 460건이었다. 이 참고값은 선별 시간만 잰 것이고, 읽고 이해하는 시간은 들어 있지 않다.

## 2. 매일 기록할 것 (7일, 하루 1분 이내)

| 항목 | 기록 방식 |
|---|---|
| 들은 시각과 함께 한 일 | 예: 07:50, 출근 지하철 |
| 끝까지 들었나 | 예 / 아니오 (멈춘 지점) |
| 화면을 봐야 이해되는 부분이 있었나 | 있으면 어떤 숫자나 내용 |
| 핵심 기억 | 듣고 2~3시간 뒤, 기억나는 소식을 적는다 → 그날 편성표와 비교해 회상률 계산 |
| 놓친 중요 뉴스 | 그날 다른 경로로 알게 된 중요한 소식이 브리핑에 없었나 |
| 불필요한 뉴스 | 빼도 됐을 이야기 수 |
| 원문을 연 기사 수, 걸린 시간 | 칸 C |
| 만족도 | 1~5 |

## 3. 지표

| 지표 | 계산 | 목표 (잠정) |
|---|---|---|
| 청취 완료율 | 끝까지 들은 날 / 7일 | 80% 이상 |
| 병행 청취 비율 | 다른 일을 하며 들은 날 / 들은 날 | 80% 이상 |
| 전용 시간 변화 | 기존 A 평균 대 새 방식 C 평균 | 줄어듦 |
| 핵심 회상률 | 기억한 이야기 / 상위 3개 이야기 | 2/3 이상 |
| 중요 뉴스 누락 | 다른 경로로 알게 된 중요 소식 중 브리핑에 없던 수 | 주 1건 이하 |
| 불필요한 이야기 비율 | 빼도 됐을 이야기 / 전체 이야기 | 20% 이하 |
| "화면이 필요했다" 횟수 | 숫자·차트 때문에 이해가 막힌 횟수 | 줄여 나감 |

**한계:**
- 사용자 1명, 7일이라 통계적 결론은 아니다.
- 기억 테스트를 스스로 하면 편향이 생긴다.
- 그래서 결과는 "가능성 확인"으로만 쓴다.
