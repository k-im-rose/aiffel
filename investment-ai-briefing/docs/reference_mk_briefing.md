# 참고: 매일경제 MAI 뉴스 브리핑의 진행 방식

- **확인한 것:** https://mai.mk.co.kr/news/briefing/detail/1545742 (2026-11-17 오전 브리핑) 페이지의 **텍스트 대본**과 출처 목록. 로그인 없이 브라우저에서 보였다.
- **확인하지 못한 것:** **오디오는 듣지 못했다** ("재생하기" 버튼은 있으나 음성 분석은 하지 않음). 그래서 목소리 수, 말 속도, 톤, 배경음은 여기서 판단하지 않는다.
- **원칙:** 대본 문장은 복제하지 않는다. 진행 구조만 참고했다.

## 텍스트에서 확인한 진행 방식

| 특징 | 내용 | 우리 대본에 반영 |
|---|---|---|
| 분야별 묶음 | 경제 / 기업 / IT·과학 세 묶음, 묶음마다 시작 시각 표시 (각 1분 30초 안팎) | 거시 / 산업 / 종목·공시 묶음 유지, 대본 리포트에 묶음별 시작 위치 표시 |
| 묶음 첫 문장 예고 | 묶음 시작에 다룰 소식 2~3개를 한 문장으로 예고 | 방송 첫 문장에서 오늘 핵심 2~3개만 예고 (인사·소개 생략) |
| 짧은 전환어 | "첫 번째 소식", "다음 소식", "마지막으로" | 대화형이라 질문으로 전환하되, 전환은 한 문장 이내 |
| 사실 → 의미 2단 구성 | 발표 기관과 수치로 사실을 말하고, 바로 다음 문장에서 "이에 따라 ~" 식으로 의미를 한 번 말함 | 사실(출처 있음) 다음에 해석을 분리해서 말함 |
| 수치에 기준 동반 | "전년보다", "최근 4년간 연평균", "올해 상반기"처럼 비교 기준과 기간을 같이 말함 | 수치는 단위·기준일·비교 기준과 함께. 검증 단계에서 확인 |
| 발표 주체 명시 | 통계 발표 기관, 감독 당국, 연구기관 이름을 문장 앞에 둠 | "누가 발표·보도했는지"를 먼저 말함 (공시 vs 기사 구분) |
| 불확실성은 짧게 | 결론이 안 난 사안은 한 문장으로 "신중한 의견이 나온다" 수준으로 처리 | "확인 필요" 설명은 방송에서 줄이고, 상세는 텍스트 리포트로 |
| 묶음 끝 한 문장 정리 | 묶음 마지막에 다룬 소식을 한 문장으로 요약 | 마지막 전체 정리 (분야별로 빠짐없이) |
| 출처 목록 | 묶음별·전체 출처 기사 목록을 화면에 제공 | `script.md`와 팟캐스트 에피소드 설명에 출처 링크 |
| 별도 탭 '맞춤형 AI 해설' | 브리핑과 별도로 기사별 해설 탭을 둠 (탭 내용은 기사 목록까지만 확인) | 방송은 짧게, 상세 확인 사항은 별도 텍스트 리포트로 분리하는 설계와 같은 방향 |

## 우리 서비스와 다른 점 (일부러 다르게 가는 것)
- MAI 브리핑은 한 사람이 읽는 형식으로 보인다(텍스트 기준). 우리는 사용자가 원한 **두 진행자 대화**를 유지한다.
- MAI는 같은 소식을 모든 독자에게 준다. 우리는 **보유·관심 종목과의 연결**을 설명하는 것이 핵심이다.
- 소식당 비중이 거의 같다. 우리는 **중요한 이야기에 시간을 더 쓰고**, 정보가 적은 날은 짧게 끝낸다.
