# 코드 리뷰 — castlegyun님의 Todo 앱

### ▶ [리뷰 PR (합쳐짐)](https://github.com/castlegyun/todo-app/pull/1) · [원본 저장소](https://github.com/castlegyun/todo-app)

AIFFEL 동료 리뷰 과제로 castlegyun님의 Todo 앱(Flask + Supabase Auth·RLS + Render)을 ART(Agent Review Template)로 리뷰했다.

- **리뷰 본문:** [REVIEW.md](REVIEW.md)
- **테스트 캡처:** [review-evidence/live-test.png](review-evidence/live-test.png) — 배포 사이트에서 직접 가입·로그인해 확인한 화면
- **방법:** 원본 저장소를 fork해 `code-review` 브랜치에 REVIEW.md를 올리고 PR을 보냈다. PR이 원본 저장소에 합쳐져 리뷰는 그쪽에도 남아 있다.
- **정리:** 리뷰에 쓰던 fork 저장소(`aiffel-review-castlegyun-todo-app`)는 할 일이 끝나서, 내가 쓴 파일만 이 폴더로 옮겼다. 상대방 코드는 복사하지 않고 원본 링크만 둔다.
